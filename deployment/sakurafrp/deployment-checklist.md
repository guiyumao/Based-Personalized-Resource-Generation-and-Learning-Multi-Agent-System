# SakuraFrp 公网演示验收清单

- [ ] 面板中核对现有 TCP 隧道：本地 `127.0.0.1:80`、远程端口和节点当前状态；轮换已粘贴到聊天的访问密钥。
- [ ] `build.ps1` 成功，`nginx.exe -t` 成功；`start.ps1` 与 `health-check.ps1` 均通过。
- [ ] 客户端日志显示隧道上线和实际公网连接地址；可信 HTTPS 证书加载成功。
- [ ] 手机关闭 Wi‑Fi，通过移动网络访问实际 `https://域名:端口/`，证书无警告。
- [ ] 首页及学生、教师、管理员路由刷新正常；无匿名越权或浏览器控制台跨域错误。
- [ ] 使用专用测试账号分别登录学生、教师、管理员端，验证各自菜单和服务端权限。
- [ ] 智能问答、多智能体学习路径、画像、知识库搜索、习题及资源生成按现有功能走通。
- [ ] 上传测试成绩单，查看解析结果；通过登录态下载受保护课件与导出报告。
- [ ] 断开并重连隧道，确认恢复；结束演示后关闭隧道并运行 `stop.ps1`。

不要用真实师生数据进行首次公网验收。任何未打勾项都不能记作已通过。
