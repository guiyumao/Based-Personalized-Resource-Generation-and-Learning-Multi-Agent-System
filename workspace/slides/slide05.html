03 多智能体协调系统 - 系统大脑

CoordinatorWorkflow 负责选智能体、排顺序、传上下文、收结果；审核智能体负责生成内容的安全与质量把关

CoordinatorWorkflow 三步编排引擎

1

analyze_intent 意图分析

理解用户请求，从 9 个智能体中选出需要参与的组合，支持 force_agents 指定和关键词自动路由。

2

dispatch_tasks 任务分发

画像先提供上下文，图谱/知识库提供依据，资源/习题/路径/问答执行生成或分析，审核节点对生成结果把关。

3

resolve_conflicts 冲突解决

处理资源生成、审核、评价反馈等先后关系；汇总成功/失败智能体，输出本轮协作摘要。

审核智能体的特殊逻辑

A

AuditService 内容审核

检查 AI 生成课件和习题是否严重跑题、明显学术错误、空内容/乱码，以及价值观或安全风险内容。

B

REJECT 后打回重生成

审核不通过时，把驳回原因写入下一轮 prompt，资源/习题智能体最多重试 2 次后再返回结果。

协调器不直接生成教学内容，而是负责组织协作；审核智能体则保证生成内容不能偏离用户需求，也不能把不合适内容交给学生。

9 个智能体的协作分工

画像 agent

学生基础、偏好、薄弱点

图谱 agent

前置依赖、结构顺序

知识库 agent

RAG grounding 内容

路径 agent

阶段路线、每日任务

资源 agent

个性化课件与讲义

习题 agent

题组、答案、解析

问答 agent

诊断式答疑与建议

反馈 agent

跨智能体综合反馈

审核 agent

检查课件/习题，不合格打回重生成

审核 agent 是生成链路的“闸门”：资源 agent 和习题 agent 的输出必须先通过审核，才能进入前端展示、评价服务和后续学习闭环。
