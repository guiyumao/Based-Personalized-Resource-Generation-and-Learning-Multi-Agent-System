12 多角色前端界面 - 协作结果的最终呈现

把多智能体输出转化为学生、教师、管理员都能理解和操作的工作台

功能作用

学生端

承接资源、习题、路径、问答、评价和画像结果，形成完整学习入口。

教师端

提供班级管理、学生洞察、教学范围设定、资源审核和教学计划干预。

管理端

负责用户角色、学科配置、系统参数、审计日志和平台运行秩序。

学生端页面

  • 仪表盘：掌握度、趋势、推荐任务和今日学习概览。
  • 学习路径：阶段目标、每日任务、完成进度和复盘安排。
  • 资源中心：查看个性化课件、讲义和推荐学习材料。
  • 习题练习：在线作答、即时评分、答案解析和错题沉淀。
  • 智能问答：结合画像和知识上下文进行教学式答疑。
  • 报告与画像：查看学习报告、错题本和画像分析结果。

前端如何承接智能体结果

资源生成结果

以课件卡片、详情页、Markdown 渲染和资源列表呈现。

路径规划结果

以阶段路线、任务清单、进度条和每日计划呈现。

评价反馈结果

以分数、解析、错题本、报告图表和行动建议呈现。

知识图谱结果

通过可交互图谱展示前置依赖、关联知识点和推荐学习顺序。

画像结果

用可解释维度展示学生状态，而不是黑盒式推荐。

系统协作关系

  • 前端通过 Axios 对接多个 FastAPI 微服务。
  • Pinia 保存用户认证状态和角色信息。
  • Vue Router 根据 student/teacher/admin 做角色路由守卫。
  • 学生端消费 AI 结果，教师端设置边界，管理端保障权限与配置。
  • 前端让智能体输出从“后台数据”变成“可操作学习流程”。

技术组成

  • Vue 3 + TypeScript + Element Plus。
  • Pinia + Vue Router + Axios。
  • vis-network 展示知识图谱。

答辩表达：前端不是壳子，而是多智能体协作结果的产品化呈现层。
