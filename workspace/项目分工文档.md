## 项目概述

本项目面向个性化学习场景，依托大语言模型、多智能体协同机制、知识库检索、知识图谱和学习评价闭环，构建面向学生、教师和管理者的智能学习支持系统。项目旨在解决传统数字学习资源供给中内容统一、个体差异适配不足、反馈链路断裂以及学习支持缺少持续优化依据等问题。

从系统形态看，项目采用前后端分离、多服务协同架构。前端以 `Vue 3 + TypeScript + Element Plus` 为主，负责学生端、教师端和管理端的交互展示与业务入口；后端当前运行主链路以 `FastAPI` 多服务架构为主，主要包括 `user-service`、`agent-service`、`resource-service`、`evaluation-service`、`teacher-service` 和 `system-service`；数据与支撑层涉及 `PostgreSQL`、`Neo4j`、向量检索能力、缓存和对象存储等基础设施。仓库中同时保留 `java-services/` 下的 `Java 17 + Spring Boot 3` 工程骨架，表明项目在开发过程中同步开展过后端工程化迁移与架构预研工作。

从业务角度看，系统主要围绕学习者画像构建、知识库检索与 RAG 支撑、知识图谱关联分析、个性化课件与资源生成、学习路径规划、学习问答、错题记录、学习报告与评价反馈展开，并在此基础上通过教师端提供教学干预入口，通过管理端提供系统治理入口，形成“画像构建、资源生成、练习与问答、评价反馈、画像更新、后续推荐”的基本闭环。

## 教师端与管理端功能说明

教师端以前端页面 `TeacherView.vue` 和后端 `teacher-service` 为主要承载模块，其功能定位是为教师提供教学组织、范围约束和学情分析的工作入口。教师端主要包括班级管理、教学范围设定、学生学习进度与学情洞察、教学分析支持以及教师角色访问控制等功能。根据项目实际承担情况，教师端相关功能由卫德翔独立负责，包括页面实现、接口接入、教师洞察展示、教学范围相关能力联调以及最终展示收口。
