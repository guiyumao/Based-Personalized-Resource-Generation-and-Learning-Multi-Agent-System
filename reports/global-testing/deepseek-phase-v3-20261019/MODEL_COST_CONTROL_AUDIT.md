# 成本控制

用户随后明确授权Chat≤30次、Search/Fetch合计≤6次、总输出≤60000 Token。独立网关在每次出站前加锁预留计数和输出上限；SDK/业务重试也必须经过同一网关，固定上游api.deepseek.com与请求模型deepseek-chat。响应usage缺失或在途状态不明确时保守计入全部预留，金额不记零。

本轮实际5 Chat+1 Search，输出3506 Token，均在限额内。网关测试覆盖30次、第31次阻断、Search/Fetch六次、第七次阻断、输出预留超限先阻断及日志不含测试密钥。专用运行器是测试治理，未补齐生产全业务预算、跨网关持久预算或账单回填。已发远程请求无法承诺立即停止计费。
