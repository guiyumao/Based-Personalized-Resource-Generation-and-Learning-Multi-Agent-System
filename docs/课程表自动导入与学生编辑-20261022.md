# 课程表自动导入与学生编辑（2026-10-22）

## 原因与调整

原课程表只读取教师排课记录。当前真实 student 账号已经加入「高一(3)班 · 数据结构与算法」与「软件243」，但两课堂均没有教师上课时间，因此原页面显示0节课。

现课程表读取当前成员关系，自动展示所有已加入且有效的课堂，不要求退出重加或手动导入。已保存的教师排课自动进入对应周；没有时间的课堂显示“待安排”，提供“安排上课时间”入口。不会从课堂名称或课程介绍推测上课时间。

学生可以：

- 为已导入课堂设置本人上课时间、每周上课日、起止日期、地点和线上/线下方式。
- 新增独立个人课程，无需加入课堂；编辑、删除后持久化保存。
- 在课堂课程卡片点击“编辑”，调整本人当次课程日期/时间/名称/地点。
- 隐藏本人课表中的当次课堂课程，在“管理个人安排”恢复教师安排。
- 点击“同步课程”重新读取最新成员关系、教师排课及本人安排。

课堂课程的个人调整只影响当前学生，不修改教师安排或其他学生课表；教师停课时，本人的对应调整也不展示。退出课堂后，课堂关联的排课与个人安排停止展示；历史个人记录保留，再加入可恢复。独立个人课程继续显示。

## 业务与接口

- 增量表 `personal_schedules`，Alembic `20261022_0040`；按 `user_id` 归属，课堂单次调整唯一 `(user_id, source_session_id, source_date)`。
- `GET /learning/schedule/me` 保留周课表响应，新增 `classrooms` 自动导入清单、`personal` 本人安排清单。课堂无排课也会出现在导入清单。
- `POST /learning/schedule/me/personal` 新增个人课程或当次课堂调整。
- `PUT /learning/schedule/me/personal/{id}` 修改本人安排。
- `DELETE /learning/schedule/me/personal/{id}` 删除个人安排或恢复原课堂安排。
- 学生角色、本人所有权、当前课堂成员、源课程有效性、日期与时间由后端验证；其他学生修改/删除返回403。

本轮同时修复上一轮F-01/F-02：跨周调课按目标日期补入；冲突检测根据常规课程及已有调停补记录计算实际占用，拦截多门课调整到同一时间。保留原有同周补课展示口径。
