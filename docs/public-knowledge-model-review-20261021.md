# 公共知识自动建设与模型审核修复

日期：2026-10-21。

缺失公共知识现在经模型生成、独立模型全文审核、正文哈希校验、公共发布及文件/索引验证后再进入学习计划或有学科上下文的生成入口。不等待管理员审批；模型拒绝最多修订一次，模型不可用或发布失败明确停止，不回退私人草稿。

新代码只向公共建设模型传递学科、主题、公共搜索材料和修订意见，不传入个人画像、附件或成绩。历史私人资料不会批量改成公共资料。已有人工治理、撤回和拒绝仍受尊重，不自动重新发布已明确下架的内容。普通GET知识搜索保持只读，教师私人教学范围不自动公开。

自动发布必须持有绑定准确正文SHA256的模型PASS记录，不能只设置AUTO_APPROVED。AI来源使用正文摘要URN，不伪造授权网站。模型审核是独立调用，并不保证无事实错误；没有真实调用质量验收时不能宣称该部分已验证。
