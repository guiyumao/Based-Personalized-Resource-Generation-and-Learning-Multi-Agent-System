# 公共生成链路修复与验收边界

2026-10-21。范围依据用户后续澄清：修复全局生成机制，学习工作区只是其中一个入口。

## 公共服务变更

- ResourceGenerationService 的检索入口统一调用 prepare_generation_context，覆盖直接资源 API、Coordinator/助手、问答触发的课件，以及导图、代码案例、视频脚本。练习服务也复用同一入口；私有教学范围继续走原有鉴权检索，不被公共上下文替换。
- Coordinator 对课件/练习统一解析已有正式学科和知识点，工作区优先使用服务端上下文的学科/知识点/当前任务目标。取得资料后知识代理、课件和题目共用上下文，避免第二次检索。
- 覆盖检查返回真正匹配主题的索引片段；索引不可用时仍可返回实际本地语料，同时保留 RETRIEVAL_FAILURE，不伪装成索引正常。
- 资料不足时，沿用现有 Search→Fetch→KnowledgeCandidate 持久化流程。最近30天、同用户/学科/知识点的 DRAFT/PENDING_REVIEW/APPROVED 候选可复用，带来源和候选编号；不会把模型正文冒充来源，也不会绕过审核直接写公共索引。默认生成入口启用补充，明确关闭仍生效；已有任务按其原始请求保持开关。
- 全局课件复用比较用户、正式知识点/学科、目标与计划、风格、学情、参考内容、篇幅/性能模式、模板hash和流水线版本。只有生成完成、审核通过、未归档且结构质量通过的同指纹资源才复用，不新建同内容资源；明确“重新生成”仍创建新资源。题目继续保留新题去重策略，不用旧题冒充新练习。
- 分章篇幅预算实际读取生成规划，fast/concise约2600字，balanced按难度4200–5500，quality约6000；九章结构保留，完整课件最低目标2400字。章节输出预算有上限，仍服从现有provider更低限额。不是首次模型耗时的实测保证。
- 清除非分章生成中的旧固定栏目/虚构学情强制指令。notes/exam按各自规划组织，课件继续使用教学合同和结构质量门禁。

## 全局课件媒体和页面

- 所有公共课件生成完成后制作本地WebM字幕视频；复用现有文件。失败单独返回media失败状态，不谎报视频已生成，也不丢弃正文。视频不需要付费模型。
- 媒体按资源内容/权限版本保存，通过鉴权接口读取。历史课件可提交持久化resource_video任务单独制作，不需要学习计划，也不需要重生成正文。内容变化后旧视频不会作为当前版本播放。
- CoursewareReader作为统一播放器入口，覆盖工作区、资源详情和独立课件页。视频为无声字幕；冒泡排序另有明确输入的比较/交换状态演示。其他学科为正文字幕页，并非自动生成教师录播或通用学科动画。
- 学习工作区挂载精确任务下的已有资源，成功后打开结果上下文；同任务练习在切换资源后仍保留，其他任务不会混入。相同知识点的其他资料折叠展示并带编号。题干/选项/解析使用共用Markdown/KaTeX。
- 禁止工作区重复点击提交，刷新可恢复当前任务轮询；已保存章节支持先读。读已有资源不会因为标题相似就自动替换为其他任务的课件。

## 尚未证明的事项

本轮未调用真实模型和真实外部Search/Fetch。因此新模板的学科准确性、首次生成总耗时、真实检索质量与现网新候选增长尚未复验；本轮不能宣称“全系统生成质量已验收通过”或“首次生成已提速多少”。现有71条模型台账不是本轮新增。历史课件正文不会被这次代码升级静默重写。公共知识库仍需通过现有审核发布流程后才能让其他用户检索。
