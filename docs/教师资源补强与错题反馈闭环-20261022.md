# 教师课程资源、补强作业与错题反馈闭环（2026-10-22）

## 实际行为

教师端“学习范围 / 学生洞察 / 作业管理”中的“课程资源与个性化补强”面板提供三个入口：

1. **发送课程资源**：选择当前课程的已有可访问资源，或编写教师专属Markdown讲义；向全班或某个在班学生发送。学生在“我的课堂”阅读发送时的内容快照，不会获得原资源的其他私有数据。
2. **生成补强作业**：选择学生、已发送给该学生的本课程资源和题量，查看最近30天真实学情，再调用已配置模型生成草稿。教师审阅、修改后下发为指定学生的作业，保留原有作业提交、通知和教师批改。
3. **学生错题与模型分析**：学生提交后，教师收到完成通知，看到题干、学生答案、参考答案、判定、简答题评分依据和模型建议。也可从原有作业提交详情查看这些结果。

**按用户最新口径：学生完成并提交后立即获得参考答案和解析，不等待教师批改。**

- 选择题服务端即时比较选项，错误记录直接进入现有错题本。
- 简答题按参考答案语义由模型评分，沿用现有评估服务的60分正确阈值；评分成功后，错误记录进入错题本。
- 模型分析在提交响应之后执行，学生无需等待分析完成才能看答案。学生与教师页面会自动刷新结果。
- 未完成评分的简答题是未知值，不按错误处理。模型失败时仍能查看参考答案，教师可以重试分析；后台任务保留在数据库，运行中的任务有5分钟执行保护与过期重试能力。
- 参考答案展示后保留首次作答；重复请求幂等，不允许覆盖答案来重写成绩或重复增加错题。

## 学情与生成依据

- 课程作答/错题按已有真实Exercise知识点归属及本课程的教学范围、资源知识点收集；不把其他课程错题纳入。
- 平台学习时长使用StudyActivity的有效区间并合并重叠，明确标为平台总时长；现有数据没有课程归属，因此不宣称是该课程学习时长。
- 课程知识点作答耗时、正确率、错题内容、原始学生答案、既有作业成绩及教师要求共同进入模型上下文。
- 无有效作答或时长记录时保留null/空证据，并以诊断练习为主，不凭空认定薄弱点。
- 每份草稿保存资源内容、学情和生成请求快照；模型失败或结构校验失败保留失败草稿，不能下发，不用模板题冒充模型题。
- 模型分析文本使用带CDATA的结构返回，避免正文引号导致JSON解析失败；仍严格校验题号、数值范围和主观题覆盖，失败不写入判错结果。

## 复用与数据边界

新增 `course_resource_deliveries`、`reinforcement_drafts`、`reinforcement_attempts` 三表，迁移0041。复用原有Assignment/AssignmentSubmission，不增设另一套学生作业系统；定向作业通过ReinforcementDraft绑定接收学生。

发布时持久化本人Exercise，提交时持久化AnswerRecord，因此学生原有错题本、知识点学习证据和教师本班学情可以读到新记录。客观题判定与主观题模型评分分开；模型分析不是教师最终人工成绩，原有教师评分和评语仍可使用。

教师仅管理本人课堂；只可发送本人资源或通过审核且公开发布的资源。指定学生必须仍是本班有效成员。其他学生无法读取定向作业、获取答案、提交或上传该作业附件。退出课堂后不再获得课堂资源与作业；本人已产生的学习记录仍属于本人。

关键接口：

- `GET /teacher/classes/{id}/resource-catalog`
- `GET/POST /teacher/classes/{id}/course-resources`
- `GET /teacher/students/me/course-resources`
- `GET /teacher/classes/{id}/students/{uid}/reinforcement-evidence`
- `GET/POST /teacher/classes/{id}/reinforcements`
- `PUT /teacher/reinforcements/{id}`、`POST /teacher/reinforcements/{id}/publish`
- 原提交接口新增结构化 `answers`；客户端耗时仅标为客户端报告，不冒充服务器核实的学习时长。
- `GET /teacher/classes/{id}/reinforcement-attempts`
- `POST /teacher/reinforcement-attempts/{id}/analyze`
