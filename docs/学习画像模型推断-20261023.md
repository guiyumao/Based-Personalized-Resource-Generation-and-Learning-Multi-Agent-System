# 学习画像由模型推断（2026-10-23）

## 背景

原“我的学习画像”页面的四维雷达只能由学生拖动滑杆手填，没有填写时雷达为空。学生要求画像由模型根据平台已经收集到的信息智能生成，而不是人工填写。

## 数据来源

`services/user_service/app/services/learning_style_inference.py` 汇总以下**本人数据**构造 Prompt：

- 自述维度 `habits.profile_dimensions`、自述学习风格 `learning_style`；
- 真实作答按知识点归集的正确率、薄弱点（`learning_content_profile`）；
- 资源浏览/探索知识点、笔记与闪卡数量；
- 最近 10 条画像对话；
- 已有的深度分析摘要（仅作辅助）。

不读取其他用户数据，不执行材料中的任何指令。

## 四轴定义

| key | 维度 | -1 | +1 |
| --- | --- | --- | --- |
| processing | 信息加工 | 沉思 | 活跃 |
| perception | 信息感知 | 直觉 | 感知 |
| input | 信息输入 | 言语 | 视觉 |
| understanding | 理解方式 | 全局 | 序列 |

模型输出需为严格 JSON：每轴 `value`（-1..1 或 null）、`confidence`（0..1）、`evidence`（≤80 字），外加 `summary`。越界、非数字、缺失轴或四项全空都会被拒绝；证据不足时保持 `null`，不以 0 冒充。

Prompt 明确：答题正确率只说明掌握/薄弱，不能单独决定任何风格轴。

## 存储与优先级

- 本人手填：`habits.learning_style_axes`（原有结构不变，**优先**）。
- 模型推断：`habits.learning_style_inference`，含 `axes`、`summary`、`model`、`generated_at`、`fingerprint`、`evidence`。
- 推断**不写入** `profile_dimensions`，避免被学习路径/资源/问答智能体误当成自述事实；辅助六维文本仍由画像对话或深度分析产生。

GET `/users/{id}/learning-portrait` 合并两层：

- 有手填值 → `source=user_reported`；
- 否则有推断值 → `source=model_inferred`，附 `confidence`、`evidence`；
- 都没有 → `source=missing`。

响应新增 `inference`：状态、生成时间、模型、`stale`、摘要、证据计数。

## 接口与成本

`POST /users/{id}/learning-portrait/infer`（本人或管理员）：

```json
{"force": false}
```

- 一次有界模型调用；24 小时内且证据指纹（Prompt 版本 + 自述维度 + 作答/资源/对话计数与最新 ID）未变时直接返回缓存；
- 新增作答、资源浏览、对话或修改自述维度后指纹变化，标记 `stale`，下次点击重新生成；
- 四项均为本人填写时跳过模型；
- 无凭据返回 `blocked`，模型输出非法返回 `failed`，证据不足返回 `insufficient`，均不覆盖已有有效推断；
- 写入保留 `updated_at`，不打断手填的乐观锁。

前端 `web-app/src/views/student/LearningPortraitView.vue`：

- 顶部“AI 生成画像/更新画像”，请求 `force=false`，无新证据时免费复用缓存；
- 雷达点与维度条按来源着色（主色=本人，蓝色=模型）；
- 模型轴展示“依据 + 置信度”；
- 进入编辑时模型推断项默认不勾选，只有勾选后才转成本人填写。

## 已知边界

- 本轮未发起真实付费模型调用，真实模型对 Prompt 的 JSON 遵从度与推断质量尚未实测；
- 未做浏览器点击级 E2E（模型调用需授权）；
- 不把推断当作心理测量结论，页面与接口均标注“可覆盖的假设”；
- 六维辅助文本不由本接口生成。
