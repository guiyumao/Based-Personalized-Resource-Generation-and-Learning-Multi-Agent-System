# 作业附件上传与教师预览（2026-10-22）

学生在「班级空间 → 课程作业」选择照片或文档，支持仅附件、仅文字或同时提交。教师在「作业管理」选择作业与学生提交后，可查看附件并批改；学生也能查看本人已提交附件。刷新页面后保留待提交附件，重新提交保留历史版本原文件；已批改作业禁止覆盖。

| 格式 | 查看方式 |
| --- | --- |
| JPG、PNG、GIF、WebP、BMP | 在线图片预览及原文件下载 |
| PDF | 浏览器内预览及原文件下载 |
| DOCX、TXT、Markdown、CSV | 安全文本预览及原文件下载 |
| DOC、Excel、PPT、ZIP、HEIC/HEIF | 原文件下载后查看 |

Word 文本预览不保留原始版式或文档内图片，完整内容请下载原文件。单个文件最多20MB，每份作业最多10个，总计100MB。文件保存原始字节，不调用模型改写。后端校验文件扩展名和签名，随机存储名，目录不对外静态开放。

学生只能访问本人附件；教师只能访问自己作业中已提交的附件，无法查看学生尚未提交的草稿。原文件下载、文本预览、删除与关联提交均有后端权限校验。已提交原件和历史版本保留，移除草稿才会删除对应草稿文件。

主要实现：`HomeworkAttachments.vue` 为两端共用组件；`homework_files.py` 路由及服务处理私有文件；`TeacherManager` 将附件与提交、修订历史关联；0036 新建 `homework_attachments` 表。后端默认存储在实际 SQLite 同目录的 `homework-files/`，可用 `HOMEWORK_UPLOAD_ROOT` 指定私有目录。基础 nginx 上传限制调整为25m，SakuraFrp 配置已有25m。
