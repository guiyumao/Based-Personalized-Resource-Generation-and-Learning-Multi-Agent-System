# 课件旧快照、目录跳转与内部Prompt追修

2026-10-21。用户截图证实上轮没有覆盖实际独立课件页，本轮补修真实入口；不将旧报告中的隔离验收等同于该入口可用。

## 已确认的遗漏

1. CoursewareView保留旧侧栏，点击仍调用document.getElementById(courseware-page-section-N)。正文已改成CoursewareReader的details，没有这些ID，点击自然失效；并非浏览器问题。
2. sessionStorage的student-workspace-courseware优先返回旧课件正文，没有回读服务端或识别旧版。数据库旧资源222为2588字符，包含已失效的60分/TCP学情；同一正式知识点459、同一用户6已存在资源225（teaching-v2，12699字符），旧入口没有连接它。旧正文不会因为后端学情重算自动改写。
3. resource_gen.md旧正文仍有旧结构，追加教学契约不够一致；exercise_gen.md上轮确实未升级。题目内部系统提示还强制根据学习速度/风格个性化，与无证据时通用出题冲突。

## 本轮修改

- CoursewareReader公开openHeading，目录直接找到实际章节并展开滚动；独立页隐藏阅读器重复目录。普通工作区和资源详情保留自己的章节目录。
- 独立页打开/刷新时回读资源正文、version和teaching_json，不把浏览器旧内容当最新。旧版明确提示，未经point-evidence-v4核验的“你的当前学习情况”段落停止展示；原始资源仍保留，不篡改历史。
- 从可见资源中查找本人、同正式知识点ID、同学科、已完成的teaching-v2新版，显示“打开已生成的九章新版”。新增knowledge_point_id到既有资源响应，避免只按名字匹配。不会静默用异主题/其他用户课件替换。
- “重新生成完整课件”使用当前阅读主题，不误用最新路径中的其他主题；成功后清除完成任务的pending键，下一次明确重生成不会又重用原完成任务。使用既有AssistantTask/Worker，读取历史课件不会触发付费生成。
- 完整重写prompts/resource_gen.md（teaching-depth-20261021）：九模块各有实质教学要求，概念→依据→例子→反例→自检；完整案例输入/中间状态/终止核验；算法索引、循环不变量、网络序号、链表别名/空表、数学绝对值/等价变形分别约束；禁止异主题学情和心理推断。
- 完整重写prompts/exercise_gen.md（exercise-depth-20261021）：题型独立合同、先独立解题验算、选择题逐项解释、过程题中间状态、主观题评分点、程序接口与至少三个测试、公式/条件/JSON规范。移除内部“必须按风格/速度个性化”要求。实际human消息传学科、章节及正式知识点ID。
- 两服务每次构建模型链重读Prompt，防止服务实例旧字符串继续使用。课件指纹及保存元数据记录模板hash/版本，避免更换提示词后混接未完成旧章节。原理/案例/练习目标900–1400字，其余500–800字；核心章输出上限3600、其他2400 Token，仍服从更低的显式环境上限。目标不是对任意模型输出质量的保证。
