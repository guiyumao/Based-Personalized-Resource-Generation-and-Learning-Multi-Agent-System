前置条件：
1. 服务已启动（与首次验证一致）：前端 `http://127.0.0.1:5175`，用户服务 8001，教师服务 8005。
2. 演示数据已初始化：`python scripts/demo_teaching_dataset.py --db artifacts/local-start-20261019/runtime.sqlite --action seed`。
3. 演示密码为 `DEMO_SEED_PASSWORD` 的值（默认见 `scripts/demo_teaching_dataset.py`）。

> 页面路径以侧边栏实际入口为准；下表同时给出路由地址便于直接访问。

| 项 | 内容 |
| --- | --- |
| 操作 | 再次执行 `--action seed` |
| 预期 | 输出 `created: {}`；教师、学生、班级、课程、作业、签到数量不变 |
| 校验 | `--action check` 的 counts 与执行前一致 |

## 验收判定

- 上述 9 项全部符合预期 → 演示环境可用于答辩与演示。
- 任一项不符合时，先执行 `--action check` 看一致性是否被破坏，再用 `--action reset --yes` + `--action seed` 重建。
- 重建会删除 `demo_%` 账号及其全部业务数据，不影响真实账号。
