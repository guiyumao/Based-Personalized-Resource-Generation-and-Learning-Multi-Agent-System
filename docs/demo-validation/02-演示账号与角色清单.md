## 4. 三种"班"的关系（重要）

```
课程 Course（6 门）
  └── 教学班 Classroom（8 个，course_id 指向课程）
        ├── 教师（4 名，一人 1~2 门课）
        ├── 排课 ClassSession（9 条，周模板）
        ├── 作业 Assignment（13 项）
        ├── 打卡任务 CheckinTask（6 个）+ 课堂考勤 AttendanceSession（6 场）
        └── 成员 ClassEnrollment（学生可属于多个教学班）

行政班 Classroom（3 个，course_id = NULL，is_public = 0）
  └── 仅用于组织学生，不含课程、作业、排课
```

- **课程**：`courses` 表，6 条，按学科命名。
- **教学班**：`classrooms` 表 + `course_id`，真实承载教学业务。
- **行政班**：复用 `classrooms` 表、`course_id` 为空、不公开，系统本身没有该实体（见审计报告 3.1）。
