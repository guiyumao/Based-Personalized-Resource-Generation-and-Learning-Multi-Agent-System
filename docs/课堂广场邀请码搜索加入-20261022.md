# 课堂广场邀请码搜索加入（2026-10-22）

学生在课堂广场原搜索框输入完整邀请码，点击搜索或回车，即可找到对应有效课堂，并点击“使用邀请码加入”。邀请码支持小写和首尾空格。原有课堂名称、学科、教师搜索继续可用。

非公开课堂只在完整邀请码精确命中时进入搜索结果；空查询、名称查询、部分邀请码不能检索到它。邀请码命中优先于学科筛选，避免旧筛选条件遮蔽对应课堂。搜索响应不返回邀请码，只新增 `invite_matched` 标记。

加入复用已有 `/teacher/students/me/classes/join`，继续校验有效邀请码、学生身份、停用状态与人数上限，重复加入不增加成员。已加入课堂显示进入入口；成员关系和课程表自动导入沿用原有机制。搜索结果绑定实际提交的查询，用户修改输入但未重新搜索时，加入仍使用当前卡片对应的查询，避免错用未提交文本；搜索请求也有过期响应保护。
