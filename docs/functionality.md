# 基于大模型的个性化资源生成与学习多智能体系统 · 当前功能文档

编写日期：2026 年 10 月 21 日。适用范围：项目介绍、功能交接、演示准备与后续开发。

本文根据当前仓库的前端路由、实际页面、后端接口、主要数据模型及近期交付记录编写。功能存在性以当前源码为依据；运行验证单独说明，不将规划、迁移骨架或上游项目宣称计为已完成功能。本次仅核对源码和文档，未重新执行全站验收。

## 1. 项目定位

系统面向学生、教师和管理员，提供浏览器访问的个性化学习与教学管理平台，围绕“学习规划—资源学习—练习评价—问题诊断—补强调整”组织连续学习过程。

“千人千面”主要体现为四类差异：

- **学什么**：结合目标、正式知识目录、先修关系及教师教学范围组织学习路径。
- **怎么学**：根据明确的学习要求、可用画像和材料生成不同讲解、案例、篇幅与课件结构。
- **练什么**：围绕当前知识点、题目要求和薄弱点生成习题，支持变式重练及补救练习。
- **下一步做什么**：根据作答、学习活动和反馈提出补强建议，由学生确认后调整后续任务。

个性化有证据边界：没有足够作答时展示“证据不足”，不将学习偏好、自评或成绩单推断直接等同于知识掌握度。小智任务默认不主动使用历史画像，需明确请求或开启对应设置。

## 4. 学生端功能

### 4.1 注册、登录与画像建立

用户注册并登录后，按身份进入对应工作台。学生画像支持对话式采集、手动维护维度、跳过采集及后续补充。

画像页面展示基础信息、目标、辅助维度、学习表现及来源。行为维度提供样本量和解释，不能作为心理测量结论。画像深度分析提供状态查询与刷新入口，结果受到可用证据数量和质量影响。

### 4.2 学习首页与活动统计

首页汇总个人计划、任务和学习活动。系统通过活动心跳记录有效学习活动，并提供日、周统计，观察学习投入与进度。

统计依据持久化记录，不将页面打开时间直接等同于有效学习时长。学生学习活动使用北京时间日周口径，管理端调用看板使用 UTC 自然日，二者需要分别理解。

### 4.3 学习路径与动态调整

学生可输入学科、学习目标及要求，生成包含阶段和任务的学习路径，查看进度并进入具体学习任务。教师教学范围可作为规划约束和参考。

主要过程：

1. 生成前检查正式学科、知识点和已发布材料覆盖情况。
2. 知识不足时说明缺口；相应模式下可形成个人临时草稿，明确不属于公共知识。
3. 查看阶段任务，进入学习内容或工作区，更新任务状态。
4. 根据学情或反馈预览调整方案，本人确认后追加后续补强任务。

路径修订具有版本冲突和重复确认保护。个人临时草稿不会因为生成成功就自动成为正式公共知识。

### 4.4 学习工作区

工作区将选定计划、模块、任务、知识点和资源绑定为服务端保存的学习上下文，集中进行阅读、问答和练习。

学生可以选择已有课件或生成内容，在同一任务下查看关联习题、提交答案、记录笔记和制作学习产物。上下文可在刷新后恢复，生成结果关联到具体任务。

服务端核验计划、资源和上下文归属及资源版本。旧个人计划和个人草稿可以进入本人工作区，但不会因此污染公共学科目录。

### 4.5 个性化课件与分章阅读

课件可以从独立课件页、工作区或小智任务触发，结合主题、目标、要求、可用材料及明确启用的学情上下文生成。

主要能力包括：

- 生成课件正文及结构化生成计划。
- 分章节组织内容，提供目录定位、分章预览及公式渲染。
- 根据讲解、逐步推演、边界情况、验算和题型分析等要求组织内容。
- 记录分章进度，支持指定章节重新生成及修订版本保存。
- 满足用户、材料、目标和模板等条件时复用本人已有成果；明确重新生成时创建新成果。
- 保存并读取历史课件，提供正文阅读和 DOCX 导出。

新课件及习题规则禁止 Mermaid flowchart/graph 流程图，改用文字步骤或状态对照表。历史正文中对应流程图由阅读器隐藏，数据库原文保留。知识图谱和思维导图是独立功能，不受此规则等同取消。

结构检查通过不能替代专家学科审核。资源复用也不等于跨用户共享私人课件。

### 4.6 习题生成、作答与即时反馈

学生可以围绕知识点、任务或课件生成结构化习题，设置数量和要求，在线提交答案并查看判分、解析和反馈。

系统支持单题和批量提交、作答持久化、工作区题目绑定、学习证据更新及后续建议。评分以服务端题目及答案为依据，并检查题目访问权限。

相同请求标识的重复提交不会重复计分或更新画像；同一标识更改答案会发生冲突，新请求标识可用于再次练习。

题目生成存在模型失败降级路径，降级题目不能作为真实模型质量验收证据。

### 4.7 错题本与收藏本

错题本汇总练习错误和经处理导入的答疑错误，支持按学科查看、解析详情、清空可见记录、变式重练和补救练习。教师可在权限范围内查看学生错题。

习题收藏本支持收藏、取消收藏及读取本人收藏。收藏保存必要题目快照，便于后续复习；收藏与答错分别记录。

### 4.8 笔记、编辑历史与闪卡

学生可以创建、编辑、删除笔记，按真实来源的学科、资源和知识点筛选，查看摘录及来源版本。

笔记保存编辑历史，并防止旧标签页覆盖较新修改。笔记可整理为闪卡，闪卡可绑定知识来源，支持到期复习、自评、复习历史及回执去重。

闪卡自评独立于习题掌握度，不自动替代答题成绩或完成学习任务。来源已经变更的卡片可以继续私人复习，但不直接作为新计划的有效任务证据。

### 4.9 智能答疑

学生输入问题后，可结合当前知识点、资源或工作区上下文获取具体教学讲解。答疑可返回结构化分析、检索片段及置信提示，并衔接课件、练习和错误复盘。

不同会话和上下文的资料范围需要隔离。检索命中不代表内容已通过权威核验，缺少已核验来源时应明确说明。

### 4.10 小智学习助手

小智提供可展开的助手入口，支持会话、流式回复、附件、个人记忆及持久任务。

主要能力包括：

- 会话创建、历史恢复及删除。
- 本人附件上传、读取和删除，用于问答、课件或习题任务。
- 按请求生成课件、习题、计划草案和组合成果。
- 查看任务状态、阶段、执行尝试及关联成果，重试失败任务。
- 请求取消排队或运行中任务。
- 确认计划草案后保存为正式个人计划。
- 管理个人助手记忆，控制历史学情使用。

任务使用现有持久任务和 Worker 执行。运行中取消属于协作式取消，在安全检查点生效，不承诺远端请求或费用立即停止。附件在排队后被删除时，执行会重新核验并明确失败。

### 4.11 资源中心与推荐

资源中心统一展示有权限的生成资源和外部导入资源，支持详情、打开来源、下载、导出及相应管理操作。

推荐综合 User-CF、Item-CF、画像、薄弱知识点及热度，记录查看、下载和打开来源等反馈。实际效果依赖资源数量及历史交互，不能仅凭算法入口宣称效果提升已量化验证。

旧学生知识库路由 `/student/knowledge-base` 当前跳转至 `/student/resources`，不再计为独立学生页面；后端知识库列表、检索与文章读取仍存在。

### 4.12 知识图谱与思维导图

知识图谱支持知识点依赖、关联资源和可视化，辅助理解先修关系。图谱读取和主动补充是不同操作，查看不等于完成全部知识建设。

本人思维导图可在资源详情或相关学习入口编辑，支持节点改名、增删、父子关系调整、缩放、保存及历史读取。保存检查版本冲突、单根和无环等约束。

私人导图编辑不会直接修改公共知识图谱。真实 Neo4j 全链运行和逐边来源完整性不在本文完成声明内。

### 4.13 学习报告与学情分析

系统提供章节、阶段、月度和综合报告相关接口。学生可查看学习分析、薄弱项、画像及学习建议。

分析使用作答、任务、活动和画像等实际证据，保留知识点归属、有效样本量与证据不足状态。归属不可靠的历史作答不能直接算入任意知识点掌握度。

画像页、深度分析页、学习分析页和报告页分别侧重个人维度、综合解释、行为趋势及阶段结果，不能将各自分值混为同一指标。

### 4.14 课堂、讨论与通知

学生可查看本人教学范围与作业，提交作业并读取批改结果。课堂相关页面和服务支持讨论、回复、通知列表及标记已读。

通知以现有业务通知为范围，不能扩展描述为管理员任意配置模板、全渠道推送或完整通知运营中心。

### 4.15 成绩单分析

成绩单模块面向学生与教师，支持导入、预览校正、分析、历史查询、分享和报告导出。

流程为：上传文件 → 校正结构化成绩 → 提交分析 → 查看统计、学情推断、薄弱科目及学习建议 → 按需查看资源、习题建议和导出报告。

支持的格式入口包括 XLSX、XLS、CSV、DOCX、PDF 和图片，上传限制为 20MB。扫描 PDF 和图片依赖 OCR 组件，缺少依赖会返回说明，不保证所有格式在所有环境成功解析。报告接口支持 Markdown、HTML、DOCX、PDF 等导出格式，结果依赖对应实现及环境。

学生本人分析可同步相关学情，但成绩单级推断不能替代题目级掌握证据。当前报告追问接口依据已保存报告组织规则式回复，不能描述为完整的大模型多轮成绩单问答。

## 6. 管理员端功能

当前导航有 **12 个页面、7 个分组**。预算设置位于看板和监控模块中，`/admin/model-budget` 是后端接口，不是独立前端页面。

### 6.1 数据看板

集中展示调用、任务、Worker、预算和 Token，并保留原账号、路径、资源及作答统计。

支持 7/30/90 天、自定义日期、按日或每 7 天聚合、图例切换、点选联动明细、搜索分页、任务详情、PNG 与同筛选 CSV 导出。各数据源可独立失败并重试，失败清除旧指标，当前未启用定时轮询。

统计口径：

- 日期使用 UTC 自然日。
- 模型和工具按真实供应商记录区分，请求模型与响应模型分别展示。
- 任务成功率分母为成功加失败，等待、运行与取消分别显示。
- 缺失 Token 标记已知小计；缓存输入已在输入内，不重复累加。
- Worker 展示登记和当前心跳状态，不虚构历史在线率。
- 未配预算不计算百分比，无可靠账单不推测费用。

### 6.2 用户与角色管理

支持搜索、分页、新增、启用/停用及现有角色分配。角色围绕学生、教师和管理员使用，不应描述为可视化自定义权限矩阵编辑器。

### 6.3 学科规划与知识建设

支持学科管理、章节与知识点规划、规划确认、知识点维护、单点和批量建设。

建设可以使用已有材料及受配置约束的 Search/Fetch 补充能力，记录来源、阶段与结果。外部工具依赖配置、网络和安全检查，接口存在不代表每次任务已使用真实搜索。

学生学习暴露的知识缺口可进入管理队列，转为知识建设请求。

### 6.4 知识文档与检索管理

支持文档上传、目录、详情、原文件、归类、学科和知识点关联、版本历史、分块、归档及转候选。

支持语料、来源和检索状态查询、增量索引、来源采集、覆盖检查与发布一致性核对。SQL 中的发布状态、版本和可见性是内容准入依据，Chroma 为检索索引，不能代替权限判断。

### 6.5 审核、发布与版本恢复

知识具有创建/修改候选、提交审核、审批、发布验证、版本比较、影响查询、回滚和撤回流程。

候选草稿不直接等于学生可检索的正式内容。发布和撤回需检查有效版本及索引一致性，避免过期或撤回内容继续进入公共检索和生成复用。

当前存在融合分类、质量评估和新增/补充/修订/重复/冲突等决策代码，但不能据此宣称全部知识自动融合及冲突处理已完成全链验收。

### 6.6 自动维护

支持维护计划创建、启停及策略调整、执行报告查询，在预算和执行规则内组织巡检及补充。自动维护不等于无条件自动发布，仍需满足相应审核与准入策略。

### 6.7 资源管理与内容改写

支持管理资源目录、预览、状态更新、发布、归档及相应删除操作。私人和公共资源仍需保留来源及权限区别。

已有管理员内容改写预览、确认应用和正文版本保存接口。改写依赖文本模型及相应调用许可，不应未经确认替换原文。

### 6.8 提示词与图文配置

支持已有 Prompt 模板维护、版本历史及恢复，管理非敏感的图片供应商名称、模型和启停状态。

图文编排已有按章节请求配图、保存图片记录、审核及插入正文的代码路径。缺少凭据或配置时返回 BLOCKED；配置就绪不能替代连通性与质量验收。当前配置状态说明仍有“后端接入待完成”的旧文案，因此按真实实现记录为“有代码路径、外部运行待验证”，不宣称完整图文链已完成验收。

### 6.9 AI 用量、预算与任务监控

支持逐次调用台账、输入/输出 Token、缓存字段、模型、功能及状态筛选，区分 LIVE 和 TEST。

预算支持平台和每用户日调用限额，持久保存后由后续调用读取。0 表示禁止新调用，留空表示不额外增加该项限制；环境限制更严格时仍有效。预算预留不等于完成调用数或实际账单金额。

监控展示助手任务、知识建设任务、阶段、执行尝试、重试、取消请求及 Worker 心跳。恢复机制涉及租约、续租和中断恢复，不承诺任意外部调用恰好执行一次。

### 6.10 配置与操作日志

支持现有系统参数读取更新、日志查询和级别筛选。敏感配置遵守后端脱敏与禁止回显规则。

## 8. 主要业务流程

### 8.1 学生自主学习

登录 → 补充画像 → 选择目标并生成路径 → 检查知识覆盖或使用已标明的个人草稿 → 打开任务工作区 → 阅读和提问 → 完成练习 → 查看反馈、错题及报告 → 预览补强方案 → 本人确认后继续学习。

### 8.2 课件及产物生成

提出主题与要求 → 核验身份和上下文 → 获取可用材料 → 判断本人已有成果是否可复用 → 创建任务并生成 → 保存资源与版本 → 打开结果 → 按需导出或制作多媒体产物。

### 8.3 教师教学

创建班级并添加学生 → 设置教学范围 → 布置作业 → 学生学习并提交 → 查看提交和学情 → 批改反馈 → 根据分析调整教学。

### 8.4 知识治理

确定学科结构 → 上传或采集材料 → 关联知识点 → 形成候选 → 审核 → 发布并验证检索 → 学生使用 → 维护巡检 → 按需修订、回滚或撤回。

### 8.5 平台运营

查看看板 → 筛选调用和任务 → 查看阶段及 Worker → 重试或取消 → 按需调整预算和维护策略 → 导出记录并查询日志。

## 10. 系统组成与代表性接口

### 10.1 运行组成

业务主链为 Vue 3、Vite、Element Plus 前端和 Python FastAPI 多服务，使用 SQLAlchemy 持久化业务，结合 Chroma 检索与独立 Worker。本地联调以 SQLite 为主。

仓库保留 Java/Spring Boot 迁移骨架，不能据此写成当前主后端。Neo4j、其他数据库、中间件及公网代理应按具体部署说明，本文不认定其全部正在运行。
