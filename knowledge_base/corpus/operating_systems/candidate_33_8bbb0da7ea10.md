## 考纲定位

考纲：I/O 管理基础（设备分类、I/O 接口与端口、I/O 控制方式、I/O 软件层次、设备接口）、设备独立软件（缓冲区管理、设备分配回收、SPOOLing、驱动程序接口）、外存管理（磁盘结构、格式化分区、磁盘调度、固态硬盘）。

## 设备与 I/O 接口

- 设备分类：按使用特性块设备（可寻址、传输单位块）与字符设备（流式、不可寻址）；按传输速率低速/中速/高速；按共享性独占/共享/虚拟设备。
- I/O 接口（设备控制器）：数据寄存器、控制寄存器、状态寄存器；端口编址统一/独立两种方式。

## I/O 控制方式（演进主线：CPU 干预越来越少）

1. 程序直接控制（轮询）：CPU 忙等读状态，CPU 与设备串行。
2. 中断驱动：设备就绪发中断，CPU 逐字（字节）传送；CPU 与设备并行但每字一次中断开销。
3. DMA：以块为单位由 DMAC 传送，仅需预处理和后处理打断 CPU；进一步降低 CPU 负担。
4. 通道：通道（能执行通道程序的弱化 CPU）控制多设备块传输，CPU 只需发启动/结束指令，中断次数更少。

## I/O 软件层次结构（自下而上）

中断处理程序 → 设备驱动程序（把上层抽象命令转为设备操作，设置寄存器）→ 设备独立软件（命名映射、保护、缓冲、分配、SPOOLing）→ 用户层 I/O 软件（库函数如 printf）。每层屏蔽下层细节；"设备独立性"指应用程序不依赖具体设备物理特性。

应用 I/O 接口：字符设备接口、块设备接口、网络设备接口（socket）；阻塞与非阻塞 I/O。

## 缓冲区管理

- 目的：缓和 CPU 与设备速度差、减少中断频率、提高并行性；单缓冲处理一块时间 = max(C, M) + T（C 处理时间、M 传送时间、T 输入时间——两数据块间隔 max(C+M, T)? 按教材公式：单缓冲每块耗时 max(C, M) + T，双缓冲 max(C + M, T)；常考比较）。
- 缓冲池（系统公用，配空闲缓冲队列）与循环缓冲；磁盘高速缓存（页缓存）。

## 设备分配与 SPOOLing

- 分配数据结构：DCT 设备控制表、COCT 控制器表、CHCT 通道表、SDT 系统设备表；分配考虑安全性与设备属性（独占/共享）。
- SPOOLing（假脱机）：用磁盘上的输入/输出井把独占设备改造为共享（虚拟）设备，如打印机——用户进程的打印请求排入输出井，由输出进程逐个打印；核心是外围操作与 CPU 处理并行，需要磁盘与中断支持，无通道也可实现。

## 磁盘与固态硬盘

- 磁盘地址 = 柱面号 + 盘面号 + 扇区号；读/写时间 = 寻道时间 + 旋转延迟 + 传输时间。
- 磁盘调度算法：FCFS；SSTF 最近优先（可能饥饿）；SCAN 电梯算法（沿一个方向服务到端再折返）；C-SCAN 单向服务（到达端直接回到另一端，等待时间更均匀）；C-SCAN/LOOK 与 SCAN/LOOK 区别（是否到磁道尽头）。计算题：给磁道号序列与起始磁头位置，求总移动道数。
- 磁盘管理：格式化（低级格式化划分扇区 + 高级格式化建立文件系统）、坏块处理；引导块、RAID。
- SSD：基于闪存，随机读写快、无机械延迟；以页读写、以块擦除，存在读/写放大与磨损均衡（动态/静态），不宜频繁随机小写（映射表与垃圾回收开销）。

## 高频考查方式与易错点

1. 单/双缓冲耗时公式比较题，注意 T、M、C 的含义与 max/min 结构。
2. 磁盘调度逐个算法手算总移动道数：SCAN 到端点才折返，LOOK 到最远请求即折返。
3. SPOOLing 的本质（虚拟设备）与所需条件。
4. 各 I/O 方式中数据流向：DMA/通道数据不经 CPU 寄存器，中断方式数据经 CPU。
