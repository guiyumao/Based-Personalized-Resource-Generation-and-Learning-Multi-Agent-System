## 基本概念与特征

- OS 是管理计算机软硬件资源、控制程序执行、方便用户使用的系统软件。资源：处理机、存储器、设备、文件。
- 四大特征：并发（宏观同时微观交替）、共享（互斥共享 + 同时访问）、虚拟（一个物理实体映射为若干逻辑对应物）、异步（进程执行速度不可预知）；并发与共享互为存在条件。

## 发展与分类

手工 → 单道批处理 → 多道批处理（宏观并行微观串行，提高利用率）→ 分时（时间片轮转、交互、独占感）→ 实时（硬实时/软实时，及时可靠）→ 网络与分布式。

## 程序运行环境（高频）

- CPU 运行模式：内核态（管态/核心态，可执行特权指令）与用户态（目态）；区分标志 PSW 的模式位。特权指令：I/O 指令、置时钟、开关中断、修改页表基址寄存器等；非特权指令如算术运算、读时钟。
- 中断与异常是用户态到内核态的唯一入口：外中断（时钟、I/O）与内中断（缺页、除零、系统调用 trap）。
- 系统调用：用户程序通过 trap（访管）指令陷入内核，由内核代为执行特权操作（如 fork、read、write），是应用程序与内核的接口；参数传递通过寄存器或内存块。
- 程序链接：静态链接、装入时动态链接、运行时动态链接；装入：绝对装入、可重定位（静态重定位）、动态运行时装入（需重定位寄存器，地址转换推迟到访问时）。
- 程序内存映像：代码段、数据段、堆（向上）、栈（向下）、共享库。

## OS 结构与引导

- 分层法（难定义层序）、模块化（内聚耦合）、宏内核（性能高，耦合大）、微内核（内核只留 IPC/基本调度/基本内存，功能在用户态服务器，可靠性可扩展但消息传递开销大）、外核（exokernel，资源多路复用库）。
- 引导过程：CPU 从 ROM 的 BIOS/UEFI 开始 → 自检 → 读 MBR/磁盘引导 → 加载启动管理器 → 装载 OS 内核（bootloader 分阶段）→ 初始化并登录。
- 虚拟机：类型 I 裸机上的 Hypervisor（如 Xen/ESXi），类型 II 宿主 OS 上的 Hypervisor（如 VMware Workstation）；虚拟化需要 CPU 对特权指令的支持（ trap-and-emulate）。

## 高频考查方式与易错点

1. 判断某指令是否特权指令（置时钟、I/O 是；读时钟、取数不是）。
2. 系统调用过程：用户态 trap 进入内核，结果返回用户态；系统调用在内核态执行。
3. 并发与并行的区别；共享的两种方式与并发的互为条件。
4. 微内核与宏内核的取舍（性能 vs 可靠性）。
