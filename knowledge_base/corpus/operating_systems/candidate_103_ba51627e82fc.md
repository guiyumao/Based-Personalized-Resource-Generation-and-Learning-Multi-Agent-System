### 内存管理：连续分配、分页、分段与虚拟内存

## 考纲定位

考纲：内存管理基础（装入链接、逻辑/物理地址、内存保护、连续分配）、分页、分段、段页式；虚拟内存（概念、请求分页、页框分配、置换算法 OPT/FIFO/LRU/CLOCK、内存映射文件、性能影响因素）。地址转换与置换算法计算年年必考。

## 内存管理基础

- 逻辑地址（虚拟）与物理地址空间；内存保护：上下限寄存器或重定位寄存器（基址）+ 界地址寄存器（限长）。
- 连续分配：单一连续分配；固定分区（内部碎片）；动态分区分配——首次适应（空闲链按地址序，找第一个够大的，综合性能通常最好）、最佳适应（按容量升序，产生最多外部碎片）、最坏适应、邻近适应（循环首次）。动态分区产生外部碎片，用紧凑（拼接）解决，代价大。内部碎片：分给进程但进程未用；外部碎片：分区之间的零头。

## 分页存储

- 离散分配，页 = 等大小块（常见 4KB），进程的页离散放入主存页框，产生内部碎片（最后一页）无外部碎片。
- 地址结构：页号 = 逻辑地址 / 页大小，页内偏移 = 逻辑地址 % 页大小；页表记录页号 → 页框号，页表寄存器 PTBR 存页表始址与长度。
- 基本地址变换：逻辑地址 → 页号 → 查页表（访存 1 次）→ 物理地址 = 页框号 × 页大小 + 偏移（再访存 1 次）。快表 TLB（相联存储器）命中则一次访存；两级/多级页表解决页表过大问题（页表也分页），各级页表大小不超过一页，访存次数相应增加。
- 计算题套路：给定页大小与页表，把十六进制逻辑地址转换为物理地址；判断越界（页号 ≥ 页表长度则越界中断）；页表项大小与页表占页数计算。

## 分段与段页式

- 分段按逻辑意义划分，段长可变；段表项 = 段长 + 基址，先比段号与段表长度，再比段内偏移与段长（双重越界检查），便于共享与保护（共享段只读）。外部碎片 + 紧凑。
- 段页式：先分段、段内分页；每进程一张段表、每段一张页表；地址 = 段号 + 段内页号 + 页内偏移，三次访存（TLB 可减）。

## 虚拟内存与请求分页

- 局部性原理（时间/空间）支撑虚拟存储；虚拟内存 = 逻辑容量扩展，最大由地址结构与外存决定。请求分页 = 分页 + 请求调页 + 页面置换；页表扩展：状态位 P、访问位 A、修改位 M、外存地址。
- 缺页中断：访问未调入页触发（内中断，一条指令期间可多次），OS 调页：有空闲页框直接装入；无空闲则按算法置换，被换出页若被修改（M=1）需写回外存。
- 页面置换算法：
  - OPT 最佳：替换未来最久不使用的页，缺页最少，不可实现作评测基准。
  - FIFO：可能 Belady 异常（帧数增加缺页反而增多）。
  - LRU：替换最近最久未使用，栈式算法无 Belady 异常，开销大（计数器/栈实现）。
  - CLOCK（NRU 简化）：循环扫描访问位，为 1 清 0 跳过，为 0 淘汰。
- 缺页率 = 缺页次数 / 访问总次数；有效访存时间 EAT = (1-p)×内存访问 + p×缺页处理时间。抖动（颠簸）：频繁调页换页，原因：分配页框过少/局部性差；工作集模型与页框分配（平均、按比例、按优先级）。
- 内存映射文件 mmap：文件映射到虚拟地址空间按需调页。

## 高频考查方式与易错点

1. 地址变换计算：页内偏移位数由页大小决定（4KB → 12 位）。
2. LRU 与 FIFO 的手算模拟：LRU 看最近使用时间戳，FIFO 看进入顺序；Belady 异常只在 FIFO。
3. 两级页表访存次数：TLB 命中 1 次、TLB 未命中 3 次（页目录、页表、数据）。
4. 分页一次访存 vs 请求分页缺页时多次访存与 I/O，EAT 计算注意单位换算。
