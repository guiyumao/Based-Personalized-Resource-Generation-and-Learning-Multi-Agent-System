### 进程与线程：状态转换、调度算法与进程通信

## 考纲定位

考纲进程管理第一部分：进程与线程（概念、状态转换、线程实现、组织控制、进程间通信）、CPU 调度（概念、目标、实现、典型算法）、上下文切换。每年 2~3 道选择题，调度算法计算（周转时间）是经典题型。

## 进程

- 进程 = 程序的一次执行过程，是资源分配的基本单位；PCB 是进程存在的唯一标志，包含标识、状态、控制/管理信息、资源清单等；进程组成 = PCB + 程序段 + 数据段。进程映像（内存布局：代码、数据、PCB、堆栈）。
- 五状态模型：运行 →（时间片到/被高优先级抢占）→ 就绪；运行 →（等待事件）→ 阻塞；阻塞 →（事件发生）→ 就绪；就绪 →（被调度）→ 运行。阻塞态不能直接转运行，运行态不能直接转阻塞。挂起（七状态）作了解。
- 状态转换判断题注意：P 操作申请资源失败 → 阻塞；V 操作唤醒对方 → 由阻塞变就绪而非运行。

## 线程

- 线程是 CPU 调度（处理机分配）的基本单位，拥有独立栈与寄存器现场；同一进程内线程共享进程的地址空间与资源（全局变量、堆、打开文件），不共享栈与寄存器。
- 用户级线程（ULT，内核不可见，切换快，一个阻塞全进程阻塞）与内核级线程（KLT，内核调度，可利用多核，切换需陷入内核）；多线程模型：多对一、一对一、多对多。

## CPU 调度

- 三级调度：作业（高级）调度控制多道程序度，进程（中级）调度即挂起/激活换入换出，进程调度（低级）从就绪队列选进程上 CPU。不可剥夺（非抢占）与可剥夺（抢占）方式；调度时机：进程终止/阻塞/时间片到/更高优先级到达等；闲逛进程 idle。
- 典型算法：
  - FCFS 先来先服务：公平、利于长作业（CPU 繁忙型），不利于短作业（I/O 繁忙型）。
  - SJF 短作业优先：平均等待/周转时间最短（该指标下最优），但饥饿、不公平。
  - HRRN 高响应比优先：R = (等待 + 要求服务) / 要求服务 = 1 + 等待/服务，等待越久响应比越高，兼顾长短作业，非抢占。
  - RR 时间片轮转：时间片过大退化为 FCFS、过小切换开销大；就绪队列先进先出。
  - 优先级调度：静态/动态优先级，可抢占/非抢占；就绪队列按优先级分层 + 各层 RR 的多级队列；多级反馈队列（MLFQ）：新进程进最高队列 RR，时间片用完降级，高层未完成被低层抢占——兼顾响应与吞吐，各队列时间片递增。
- 指标计算：周转时间 = 完成时刻 - 到达时刻；带权周转 = 周转 / 服务时间；等待时间 = 周转 - 运行。响应时间（交互）。

## 上下文切换

切换时保存当前进程 CPU 现场（PC、PSW、通用寄存器）到 PCB、恢复目标进程现场；切换只能发生在内核态，开销大（含 cache 刷新的间接开销）。

## 进程间通信 IPC

- 共享内存： fastest，需同步互斥配合（互斥锁/信号量）。
- 消息传递：直接通信（send/receive 指明目标）与间接（信箱）；消息队列。
- 管道：半双工字符流（需双向建两条），限于父子/兄弟进程，读空写满均阻塞。
- 信号与 socket 作了解。

## 高频考查方式与易错点

1. 状态转换图的反向箭头（阻塞→运行不存在）。
2. 调度算法甘特图计算：按到达时间逐个安排，注意抢占时刻（SJF 抢占式/非抢占式结果不同）。
3. 时间片 RR 中新到达进程放在刚被剥夺进程之前还是之后（约定：用完时间片的进队尾，之后到达的按到达序）。
4. 线程共享/不共享资源清单；用户级线程与内核级线程调度归属。
