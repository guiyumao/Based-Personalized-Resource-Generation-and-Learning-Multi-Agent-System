### 同步与互斥：信号量、管程、经典问题与死锁

## 考纲定位

考纲：进程同步基本概念、临界区互斥的软件/硬件实现方法、锁、信号量、条件变量、经典同步问题（生产者-消费者、读者-写者、哲学家进餐）、死锁（概念、预防、避免、检测解除）。PV 操作题是综合题常客。

## 基本概念

- 临界资源：一段时间内仅允许一个进程使用的资源；访问分进入区、临界区、退出区、剩余区四部分。
- 同步：协作进程按序推进；互斥：多个进程不能同时进入临界区。准则：空闲让进、忙则等待、有限等待、让权等待。

## 软硬件实现

- 软件：单标志（违背空闲让进）、双标志先检查（违背忙则等待）、双标志后检查（饥饿）、Peterson 算法（谦让 flag + turn，满足四准则）。
- 硬件：中断屏蔽（不适用于多核）、TestAndSet（TS 指令）、Swap 指令；硬件方法简单但忙等（不满足让权等待）。

## 互斥锁

acquire/release；自旋锁（忙等，多核且临界区短时效率高）与互斥锁（阻塞等待）。

## 信号量与 PV 操作

- 整型/记录型信号量 S：P(S)（wait）——S 减 1，S < 0 则阻塞入 S 队列；V(S)（signal）——S 加 1，S ≤ 0 则唤醒一个等待者。S 的绝对值 = 等待进程数。
- 信号量实现互斥：临界区前 P(mutex)，后 V(mutex)，mutex 初值 1。
- 实现前操作后操作同步：前 V 后 P，信号量初值 0。
- 管程：把共享数据及操作封装，每次仅允许一个进程进入（互斥自动实现），条件变量 condition 的 wait/signal 实现阻塞同步。

## 经典问题（必背模板）

- 生产者-消费者（单缓冲/多缓冲）：互斥 P(mutex) 与同步 P(empty)/P(full) 的顺序——先同步 P 再互斥 P，否则死锁；两个 V 顺序可交换。
- 读者-写者：读读共享、读写互斥、写写互斥；计数器 count 上加 count 互斥保护；写者优先/读写公平（加排队信号量 w）变体。
- 哲学家进餐：5 人 5 筷，防死锁方案：至多 4 人同时拿、奇数号先左偶数号先右、一次拿齐（P 两支筷子用信号量组，拿不到则都放下/仅当两支都可用才拿起）。
- 吸烟者、理发师问题作扩展了解。

## 死锁

- 死锁：多个进程互相等待对方资源而永久阻塞。必要条件四条：互斥、不可剥夺、请求并保持、循环等待——破坏任一即可预防：一次性申请全部资源（破坏请求保持）、可剥夺、资源有序分配（破坏循环等待）。互斥条件不能破坏。
- 死锁避免：系统安全状态（存在安全序列则安全）；银行家算法——Available、Max、Allocation、Need = Max - Allocation；试找 Need_i ≤ Work 的进程逐个回收资源，全部可完成则安全。安全状态必无死锁，不安全状态未必死锁。
- 死锁检测：资源分配图，能化简（找出非阻塞边不断消去）则无死锁；检测到死锁后解除：剥夺资源、撤销进程、进程回退。
- 不会死锁的情况判断：各进程申请资源不超过系统拥有、申请总量可控时。

## 高频考查方式与易错点

1. PV 操作综合题：先列互斥与同步关系（资源数量对应信号量初值），再按"先同步后互斥"组装。
2. 信号量物理意义：S < 0 时 |S| 为等待进程数；初值表示资源数（互斥为 1，同步为 0 或资源数）。
3. 银行家算法手算：先算 Need 矩阵再逐个尝试，写出安全序列。
4. 死锁预防（静态限制）与避免（动态判断安全状态）概念区分。
