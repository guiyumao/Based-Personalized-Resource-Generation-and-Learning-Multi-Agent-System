## 考纲定位

存储器层次结构是 408 重中之重：分类与层次结构、SRAM/DRAM/Flash、主存（DRAM 芯片、多模块存储器、与 CPU 连接）、外部存储（磁盘、SSD）、Cache（工作原理、映射、替换、写策略）、虚拟存储器（页式、段式、段页式、TLB）。 Cache 计算题几乎年年必出。

## 层次结构与分类

- 层次结构：寄存器 → Cache → 主存 → 辅存（磁盘/SSD/磁带）；前两层解决速度匹配（对程序员透明），Cache-主存层由硬件自动管理，主存-辅存层由硬件 + OS 管理（虚拟存储）。
- 按在系统中的作用：主存/辅存/缓存；按存取方式：RAM（随机）、SAM（顺序）、DAM（直接）、CAM（相联，按内容）；按可改写性、易失性分类；存放一个二进制位的物理器件是存储元。

## 半导体存储器

- SRAM：触发器存储，非破坏性读出，快、贵、功耗大，用作 Cache；DRAM：电容存储，需定时刷新（集中/分散/异步刷新），破坏性读出（读后再生），用作主存。DRAM 刷新按行进行，刷新对 CPU 透明。
- Flash（闪存）：U 盘/SSD，写前须擦除（按块擦），擦写次数有限（磨损均衡）；SSD 由闪存芯片 + 控制器组成，随机读写快于磁盘但存在写放大。
- 主存与 CPU 连接：地址线/数据线/片选/读写控制；位扩展（加大字长）、字扩展（加大容量）、字位同时扩展。ROM：MROM/PROM/EPROM/EEPROM/Flash，BIOS 用 ROM 存放。
- 多模块存储器：连续（顺序）编址串行访问；交叉（交叉编址）并行访问，m 体低位交叉在流水线方式下连续读取 m 个字的时间 ≈ T + (m-1)r（T 存取周期，r 总线传送周期），可提高带宽。

## 外部存储器

- 磁盘：磁道/扇区（常见 512B），存取时间 = 寻道时间 + 旋转延迟（平均半圈）+ 传输时间；RAID 0 条带（无冗余）、RAID 1 镜像、RAID 5 分布式奇偶校验等。

## Cache（计算题核心）

- 命中率 H = 命中次数/总访问次数；平均访问时间 = H × Tc + (1-H) × Tm（Tc 命中访问时间，Tm 未命中主存访问时间，考虑并行/串行方式）。
- 地址映射：
  - 直接映射：Cache 行号 = 主存块号 % Cache 行数，主存地址 = 标记 | Cache 行号 | 块内地址；冲突率高，硬件简单。
  - 全相联：任意块放任意行，标记为完整块号，比较开销大（相联存储器）。
  - 组相联：组间直接、组内全相联；主存地址 = 标记 | 组号 | 块内地址。2 路指每组 2 行。
- 计算题要点：块大小与块内地址位数（log2 块字节数）、行数、标记位数（主存地址位数 - 组号位 - 块内地址位）、命中/缺失判断序列（LRU 模拟）。
- 替换算法：FIFO、LRU（最近最少使用，需计数器）、LFU、随机；直接映射无需替换算法。
- 写策略：写命中——全写法（write-through，同时写主存，配写缓冲）与回写法（write-back，仅改 Cache 行并置脏位，换出时回写）；写不命中——写分配法（调入块，常配回写）与非写分配（直接写主存，常配全写）。
- 一致性问题：多 Cache（多核）一致性，MESI 等协议思想。

## 虚拟存储器

- 页式：虚拟地址 = 虚页号 + 页内偏移；页表存主存，虚页号查页表得页框号；缺页时 OS 调页。有效位/修改位/访问位。TLB（快表）是页表的 Cache（相联存储器），TLB 命中则免访存查页表；TLB 与 Cache 查找可并行。地址转换成功后再访问主存：TLB 命中访存 1 次，未命中且页表命中访存 2 次。
- 段式：按逻辑模块分段，段表项记录段长与基址，便于共享保护但产生外部碎片；段页式先分段再段内分页，取一次数据最多三次访存（段表、页表、数据，TLB 可加速）。
- 页式虚拟存储与 Cache 对比：缺页由 OS 异常处理、替换算法（LRU/Clock）、写回策略（脏位）。

## 高频考查方式与易错点

1. 组相联主存地址划分与标记位数计算：总位数 = 标记 + 组号 + 块内地址。
2. LRU 模拟题：记录每行最近使用时间，替换最久未用的。
3. 写策略搭配：回写配写分配、全写配非写分配。
4. 平均访问时间公式区分并行查找与串行（先 Cache 后主存）两种模型。
5. DRAM 与 SRAM 特性表（刷新、是否破坏性、用途）。
