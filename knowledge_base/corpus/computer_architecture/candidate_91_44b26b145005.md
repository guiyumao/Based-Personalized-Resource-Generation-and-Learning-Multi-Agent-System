### 中央处理器：数据通路、控制器、异常中断与指令流水线

## 考纲定位

CPU 章考纲：CPU 功能与基本结构、指令执行过程、数据通路、控制器（硬布线与微程序）、异常与中断机制、指令流水线（概念、实现、三类冒险、超标量与动态流水线）、多处理器基本概念。数据通路分析、流水线计算与中断处理是选择题+综合题双料考点。

## CPU 功能与结构

- 功能：指令控制、操作控制、时间控制、数据加工、中断处理。
- 寄存器：用户可见（通用寄存器、PC 可见性因机型而异）与用户不可见（MAR、MDR、IR、微指令寄存器）；PC 存放下条指令地址，IR 存当前指令。

## 指令周期与数据通路

- 指令周期 = 取指 → （间址）→ 执行 →（中断）周期；取指对任何指令都相同，执行周期因指令而异。
- 数据通路：寄存器间传送信息的路径。单总线结构：各部件分时用一条内部总线，冲突时需暂存（如执行加法需把两个操作数先存入暂存器 Y、Z）；专用通路（多总线）结构支持并行，是流水线基础。
- 指令执行举例（单总线）：ADD (R0), R1 —— 取指 → 取操作数（经 MAR/MDR）→ ALU 运算经 Z 回写。

## 控制器

- 硬布线控制器：组合逻辑直接产生微操作控制信号，速度快，设计复杂、修改难，RISC 采用；微操作节拍安排（取指、间址、执行各周期控制信号序列）。
- 微程序控制器：把每条机器指令编写成微程序存于控制存储器 CM（ROM）；微指令 = 微操作码字段（水平型直接控制/字段译码，垂直型类似机器指令）+ 下地址字段；一条机器指令对应一段微程序，取指微程序公共。微地址形成：下地址字段、增量计数、映射（操作码散列）。
- 对比：硬布线快但灵活性差；微程序规整易扩充但慢于硬布线。

## 异常与中断

- 异常（内中断，来自 CPU 内部）：故障 fault（缺页、除 0，可修复后重新执行）、自陷 trap（系统调用、断点）、终止 abort（硬件错误）。中断（外中断）：可屏蔽（INTR 引脚）与不可屏蔽（NMI）。
- 响应条件与时机：每条指令执行结束时检查；中断隐指令完成：关中断、保存断点（PC/PSW）、引出中断服务程序入口（向量地址）。中断处理：保存现场（通用寄存器）→ 服务 → 恢复现场 → 开中断返回。多重中断（中断嵌套）需在中断服务内开中断，屏蔽字改变响应优先级；处理优先级与响应优先级不同。
- 中断判优：硬件排队器或软件查询；向量中断通过中断向量表定位服务程序。

## 指令流水线

- 经典五段：IF 取指 → ID 译码/取数 → EX 执行 → MEM 访存 → WB 写回。设每段时间 τ，n 条指令流水执行时间 = (k + n - 1)τ（k 段）；吞吐率极限 1/τ，加速比 ≈ k；吞吐率 = n / ((k+n-1)τ)。
- 冒险与处理：
  - 结构冒险：部件冲突（如 IF 取指与 MEM 访存争存储器）——指令存储器与数据存储器分开（哈佛结构）或暂停。
  - 数据冒险：后指令用到前指令结果——转发/旁路（旁路 EX 结果到 ALU 输入）、load-use 冒险需一拍气泡 + 转发、编译器调度。
  - 控制冒险：转移指令改变 PC——分支预测（静态预测方向、动态预测 BTB）、延迟分支、提前形成条件码。
- 超标量：一个时钟周期发射多条指令（多发射接口），需多套部件；超流水：细分流水段提高主频；动态调度（乱序执行）、动态分支预测概念。

## 多处理器基本概念

- SISD/SIMD/MIMD 分类；向量处理器；硬件多线程（细粒度、粗粒度、同时多线程 SMT）；多核；SMP 共享内存多处理器；缓存一致性。

## 高频考查方式与易错点

1. 流水线执行时间与吞吐率计算，含冒险停顿时钟数（如 load-use 停 1 拍、分支停若干拍）。
2. 数据通路写操作步骤：单总线上 ALU 两个输入需要暂存器，别漏。
3. 微指令水平型/垂直型、微程序与机器指令的对应层级关系。
4. 中断隐指令做了什么（硬件自动）与中断服务程序做什么（软件）分开记。
