## 指令格式

- 指令 = 操作码 + 地址码（零/一/二/三/四地址指令）。定长操作码 vs 变长（扩展）操作码：扩展操作码需满足前缀码不冲突，n 位操作码可表示 2^n 种，缩短一类则留出该组合给扩展使用——常考"某指令系统共有 m 条三地址指令还能有二地址指令多少条"这类计算。
- 指令字长 = 操作码 + 地址码位数；按字节编址、指令字长为 2 的倍数字节对齐。

## 寻址方式（核心考点）

设 EA 为有效地址，A 为地址码字段：

- 立即寻址：操作数 = A 本身（指令中），取指即得，最快，不能被修改。
- 直接寻址：EA = A，访存 1 次取数。
- 间接寻址：EA = (A)，先取 A 内容再访存，共 2 次（多次间接再 +1），扩大寻址范围。
- 寄存器寻址：操作数在寄存器 R 中，不访存；寄存器间接寻址：EA = (R)，访存 1 次。
- 相对寻址：EA = (PC) + A，常用于转移指令，便于程序浮动（代码与位置无关）。
- 基址寻址：EA = (BR) + A，BR 由 OS 管理，面向系统，利于多道程序重定位。
- 变址寻址：EA = (IX) + A，IX 用户可改，适合数组循环处理（A 为数组首址，IX 为下标）。
- 堆栈寻址：硬堆栈（寄存器）与软堆栈（主存），SP 指向栈顶；进出栈 SP 变化方向取决于栈的生长方向。

偏移寻址汇总：基址（基址寄存器 + 偏移 A）、变址（变址寄存器 + 形式地址 A）、相对（PC + A），均为寄存器内容与指令地址码相加，但寄存器归属与用途不同。

## CISC 与 RISC

- CISC：指令多而杂、变长、微程序实现、指令周期长、访存指令多、少用流水线。
- RISC：指令少、定长、多为寄存器-寄存器型（LOAD/STORE 结构访存）、硬布线控制器、大量通用寄存器、适合流水线、优化编译；CPI 通常 ≤ 1.5，配合超标量可更低。

## 高级语言与机器级对应（x86/AT&T 基础概念）

- 编译器：高级语言 → 汇编；汇编器：汇编 → 机器码（重定位目标文件）；链接器：合并多个目标文件与库，完成符号解析与重定位生成可执行文件；加载器装入内存。
- 选择语句：比较指令设置标志位 + 条件转移（分支预测概念）；循环：初始化、条件判断（常倒序比较）、体、更新；函数调用：call 压入返回地址，ret 弹回；参数传递（寄存器/栈）、返回值寄存器、栈帧（rbp/rbp 概念，保存现场）。
- 大端：数据高位字节存低地址；小端相反（x86 为小端）；结构体对齐规则按成员最大对齐值。

## 高频考查方式与易错点

1. 各寻址方式访存次数与有效地址公式：间接寻址别漏掉取间址单元那一次。
2. 扩展操作码计算题：按"短码留长码空间"的树状结构核算。
3. 相对寻址转移目标 = 取指后 PC 值（已指向下一条）+ 偏移，注意 PC 是更新后还是更新前。
4. 基址面向系统、变址面向用户的区别易混。
