### 总线与输入输出系统：总线标准、中断、DMA 与 I/O 接口

## 考纲定位

考纲：总线基本概念、组成与性能指标、总线事务与定时；I/O 接口功能结构与端口编址；程序查询、程序中断、DMA 三种 I/O 方式。中断与 DMA 对比是每年必考。

## 总线

- 定义：连接多个部件的公共信息传输干线；特点分时、共享。三类：数据总线（双向，位数 = 机器字长相关）、地址总线（单向，位数决定寻址空间）、控制总线。
- 性能指标：总线带宽 = 总线工作频率 × 总线宽度（B/s，宽度按字节）；总线标准 PCI、PCIe（串行点对点）、USB 等；主设备发起、从设备响应。
- 总线仲裁：集中式——链式查询（BG 串行，优先级固定，近主控者高）、计数器定时查询、独立请求（并行，速度快、控制线多）；分布式仲裁（自优竞赛）。
- 总线事务与定时：请求→仲裁→寻址→传输→释放。定时方式：同步定时（统一时钟，速度快但须迁就最慢设备）与异步定时（握手：不互锁、半互锁、全互锁，全互锁最可靠最慢）；半同步（加 WAIT）与分离式总线事务（传输线路上拆成两事务，总线利用率最高）。

## I/O 接口与编址

- 接口功能：选中设备、传送信息、状态反馈、电平与格式转换等。结构：数据缓冲寄存器 DBR、状态寄存器、控制寄存器；端口 = 接口中可寻址的寄存器，端口地址 = 端口号。
- 端口编址：统一编址（与主存一起，访存指令操作 I/O，缺点占用主存空间、指令长）；独立编址（专用 IN/OUT 指令，地址空间独立，需控制信号区分）。

## 三种 I/O 方式

- 程序查询：CPU 反复读取状态位直至设备就绪，独占 CPU，效率最低；CPU 与设备串行工作。
- 程序中断：设备准备好后向 CPU 发中断请求，CPU 在指令周期末响应，中断隐指令（关中断、保断点、引服务程序）+ 服务程序处理，一次数据传送（CPU 执行传送指令），之后恢复。CPU 与设备并行，适用于低速设备、键盘等；中断处理过程含保存现场/恢复现场等软件开销。响应条件：允许中断且一条指令执行完。中断接口组成：中断请求触发器、中断屏蔽触发器、排队器等。
- DMA：DMA 控制器（DMAC）接管总线直接在主存与设备间传送，CPU 仅在传送前初始化与结束后处理（中断方式通知）。DMAC 组成：主存地址计数器、字计数器、数据缓冲、中断逻辑。传送方式：停止 CPU 访存（独占）、周期挪用（窃取，最常用）、交替访存。适用于高速块设备（磁盘）。DMA 与中断的区别：数据传送不经过 CPU（不进 CPU 寄存器）、响应时机（DMA 可在存取周期末、一条指令执行完均可）、硬件开销。

计算：DMA 方式传送 1 个数据块 CPU 仅被打断两次（预处理 + 后处理），中断方式每个数据（字/字节）打断一次。

## 高频考查方式与易错点

1. 总线带宽计算：注意单位换算与工作频率 × 宽度。
2. 三种 I/O 方式 CPU 干预程度排序与适用场景。
3. 中断响应优先级 vs 处理优先级（屏蔽字改变的是处理优先级）。
4. DMA 请求优先级高于中断请求（丢失数据风险）；DMA 结束时仍需中断通知 CPU 后处理。
