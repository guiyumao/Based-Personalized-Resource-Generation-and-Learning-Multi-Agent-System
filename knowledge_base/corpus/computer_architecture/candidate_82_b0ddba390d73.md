### 计算机系统概述：层次结构、工作方式与性能指标

## 考纲定位

考纲第一部分：计算机系统层次结构（基本组成、硬件结构、软硬件关系、存储程序工作方式）、程序与指令执行过程、性能指标（吞吐量、响应时间、主频、CPI、MIPS、FLOPS 等）。每年 1~2 道选择题，性能指标计算是重点。

## 冯·诺依曼结构

- 核心思想：存储程序——程序与数据一同以二进制形式预先存入存储器，机器按地址自动逐条取指执行。
- 五大部件：运算器、控制器（合称 CPU）、存储器、输入设备、输出设备；以运算器为中心（现代机器改为以存储器为中心）。
- 指令与数据同存于存储器、按地址访问；指令由操作码 + 地址码构成。

## 计算机系统层次

- 从高到低：高级语言机器（虚拟）→ 汇编语言机器 → 操作系统机器 → 机器语言机器 → 微程序机器（硬件级）。
- 编译：整体翻译高级语言为目标程序再运行（C）；解释：逐句翻译执行（Python），编译型执行快。
- 软硬件逻辑功能等价：某功能可由硬件也可由软件实现；固件 = 微程序写入 ROM。

## 程序与指令执行过程

- 高级语言 →（编译/汇编）→ 机器语言；程序装入内存后，PC（程序计数器）给出指令地址，取指 → 译码/分析 → 执行，PC 自动加"1 条指令长度"指向下一条（转移指令时改为转移目标）。
- 取指令、取操作数均访存；指令周期 = 取指周期 +（间址）+（执行）+（中断）周期。

## 性能指标（计算必考）

- 主频 f（Hz），CPU 时钟周期 = 1/f；CPI = 执行一条指令所需平均时钟周期数。
- CPU 执行时间 = 指令条数 × CPI / 主频 = CPU 时钟周期数 / 主频。
- MIPS = 指令条数 / (执行时间 × 10^6) = 主频 / (CPI × 10^6)；MFLOPS/GFLOPS/TFLOPS 衡量浮点性能。
- 综合题套路：程序含不同类型指令（各占比与各自 CPI），求整体 CPI = Σ(比例 × CPI_i)，再求执行时间与 MIPS；主频提高而 CPI 变化时对比总时间。
- 吞吐量（单位时间完成的工作量）与响应时间；基准程序（benchmark）评测；Amdahl 定律思想：加速受限于不可优化部分。

## 数据字长与存储

机器字长 = CPU 一次能处理的二进制位数（寄存器位数）；指令字长、存储字长可与机器字长不同；按字节编址时字长 32 位 = 4B。

## 高频考查方式与易错点

1. CPI/MIPS/执行时间三者的换算链，别把 MIPS 与主频混用。
2. 冯·诺依曼机"以存储器为中心"是现代改进，经典模型以运算器为中心。
3. 指令周期各阶段的访存次数（取指 1 次 + 间址 1 次 + 存结果 1 次）。
4. 字长与按字节编址下地址位数的计算（如 4GB 主存需 32 位地址）。
