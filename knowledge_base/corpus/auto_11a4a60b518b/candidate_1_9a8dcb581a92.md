# Python 循环结构

> 本文为模型生成的知识内容，未引用外部教材或文档；示例均可在标准 Python 3 解释器中直接运行验证。

## 一、定义与适用条件

**循环结构**是让一段代码在满足条件时被重复执行的程序控制结构。Python 提供两种原生循环：

| 结构 | 语义 | 典型适用场景 |
|---|---|---|
| `while` | 先判断条件，条件为真则执行循环体，执行完再判断 | 循环次数事先未知，由状态或条件决定终止 |
| `for` | 对可迭代对象逐个取元素，取完即止 | 遍历序列、`range`、字典、文件行等已知集合 |

两者都可配合 `break`（立即终止整个循环）、`continue`（跳过本次剩余语句，进入下一次迭代）、`else` 子句（循环**未被 break 中断**而正常结束时执行）。

**适用条件**：重复逻辑相同、每轮仅依赖少量变化的状态；且必须存在可保证终止的机制（`while` 的条件最终变假，或 `for` 的可迭代对象有限）。若循环体无副作用且无终止保证，则不适合用循环表达。

## 二、原理与推导

### 1. `while` 的执行模型

`while cond: body` 等价于反复执行：

1. 求值 `cond`，得到布尔真值（Python 中任何对象都有真值）；
2. 若为假，跳出循环，执行 `else` 子句（若有）；
3. 若为真，执行 `body`，回到第 1 步。

**终止性推导**：设循环前状态为 $S_0$，每轮把状态映射为 $S_{i+1}=f(S_i)$。若存在度量函数 $m(S)$ 取值于良序集（如非负整数），且每轮严格减小、下界为 0，则循环必终止。这是写 `while` 时应当能口头给出的论证。

### 2. `for` 的执行模型

`for x in it: body` 内部先调用 `iter(it)` 取得迭代器，然后反复调用 `next()`：

- 返回元素则绑定给 `x` 并执行 `body`；
- 抛出 `StopIteration` 则结束循环（不向外传播），执行 `else` 子句（若有）。

因此 `for` 的循环次数等于可迭代对象产出的元素个数；对 `range(a, b, s)` 而言，元素个数为

$$\max\left(0,\ \left\lceil \frac{b-a}{s} \right\rceil\right)$$

（$s>0$ 时；$s<0$ 时对称处理）。这解释了 `range(0, 10, 3)` 产出 `0,3,6,9` 共 4 个元素。

### 3. `else` 的语义推导

`else` 绑定在“循环正常走完”这一事件上，而非“条件为假”。`break` 会跳过 `else`。因此 `for ... else` 常用于“查找未命中”的判定：找到即 `break`，未找到则走 `else`。

## 三、完整步骤

### 步骤 A：写一个可终止的 `while`

1. 明确循环不变量（每轮开始时恒成立的事实），例如“`total` 等于已累加的前 `i` 项之和”。
2. 在循环外初始化所有被修改的变量。
3. 写出条件，确保条件依赖的变量在循环体内被推进。
4. 在循环体内先推进状态、再做业务处理，或反之，但必须保证每轮至少推进一次。
5. 用一个小规模输入手工模拟 2～3 轮，确认不变量与终止条件。

### 步骤 B：写一个 `for` 遍历

1. 确定数据源是可迭代对象（列表、字符串、`range`、字典视图、生成器等）。
2. 若需要索引，用 `enumerate`；若需并行遍历，用 `zip`；不要用 `range(len(x))` 再下标访问，除非确实需要按下标改写。
3. 若循环中要修改正在遍历的容器，先复制（`for x in lst[:]`）或改为构造新容器，避免迭代器失效。
4. 需要提前退出时用 `break`，需要跳过时用 `continue`，并检查 `else` 是否被意外触发。

### 步骤 C：嵌套循环

1. 外层控制“组”，内层控制“组内元素”。
2. `break` 只跳出**最内层**循环；要跳出多层，用标志变量或把内层封装成函数后 `return`。
3. 估算复杂度：两层各 $n$ 次即 $O(n^2)$，注意数据规模。

## 四、可验算案例

### 案例 1：`while` 求最大公约数（欧几里得算法）

```python
def gcd(a, b):
    a, b = abs(a), abs(b)
    while b != 0:
        a, b = b, a % b
    return a

print(gcd(48, 18))   # 6
print(gcd(17, 5))    # 1
print(gcd(0, 9))     # 9
```

**手工验算**：`(48,18) → (18,12) → (12,6) → (6,0)`，返回 6。不变量：每轮开始时 `gcd(a,b)` 与原输入的最大公约数相同（因 $\gcd(a,b)=\gcd(b,a\bmod b)$）。终止性：`b` 严格减小且非负，必到 0。边界：`gcd(0,9)` 首轮即 `(9,0)`，返回 9；`gcd(0,0)` 返回 0，需在调用处约定。

### 案例 2：`for` 统计与 `else` 查找

```python
nums = [3, 7, 12, 25, 40]
total = 0
for n in nums:
    if n % 2 == 0:
        total += n
print(total)          # 52 = 12 + 40

target = 25
for n in nums:
    if n == target:
        print("found", n)
        break
else:
    print("not found")
# 输出 found 25
```

**验算**：偶数 12、40，和 52。查找 25 命中并 `break`，`else` 不执行；若把 `target` 改为 99，则走 `else` 输出 `not found`。

### 案例 3：`range` 元素个数

```python
print(list(range(0, 10, 3)))   # [0, 3, 6, 9]
print(len(range(0, 10, 3)))    # 4
print(list(range(5, 0, -2)))   # [5, 3, 1]
```

**验算**：$\lceil (10-0)/3 \rceil = \lceil 3.33 \rceil = 4$，与 `len` 一致；负步长 `range(5,0,-2)` 产出 5、3、1，共 3 个。

## 五、边界与反例

| 情形 | 结果 / 说明 |
|---|---|
| `while True:` 且无 `break` | 死循环；必须有外部终止手段（`break`、异常、`return`） |
| `for i in range(0)` | 循环体一次不执行，`else` 会执行 |
| `for` 中 `break` | `else` 被跳过 |
| 遍历中 `lst.remove(x)` | 迭代器跳过元素，结果错误；应遍历副本或重建列表 |
| `range(10, 0)` | 空序列，因默认步长 +1 无法从 10 到 0 |
| `while` 条件依赖浮点累加 | 可能因精度误差永不精确相等，应改用整数计数或容差比较 |
| 嵌套 `break` | 只跳出最内层，外层继续，易被误认为全部退出 |
| `continue` 在 `while` 中放在状态推进之前 | 状态不推进，可能死循环 |

**反例**：下面代码意图删除所有偶数，实际会漏删：

```python
lst = [2, 4, 6]
for x in lst:
    if x % 2 == 0:
        lst.remove(x)
print(lst)   # [4]，而非 []
```

原因：删除 `2` 后列表变为 `[4,6]`，迭代器下标已前移，跳过 `4`。正确写法是 `lst = [x for x in lst if x % 2]` 或遍历 `lst[:]`。

## 六、常见错误

1. **忘记推进循环变量**：`while i < n:` 内不写 `i += 1`，导致死循环。
2. **`range` 边界混淆**：`range(n)` 是 `0..n-1`，不含 `n`；`range(a,b)` 不含 `b`。
3. **误用 `else`**：以为 `else` 是“条件为假时执行”，实际是“未被 `break` 时执行”。
4. **在 `for` 中修改被遍历容器**：迭代器失效，结果不可预期。
5. **`break` 与嵌套**：以为 `break` 能跳出两层。
6. **`while` 条件写成赋值**：`while x = 1:` 是语法错误（Python 不允许），但 `while (x := 1):` 是合法且恒真的，需警惕。
7. **用 `for` 做本应 `while` 的事**：如“直到收敛”的迭代，用 `for` 需人为设上限，应明确上限并检查是否提前收敛。
8. **忽略空序列**：`for` 对空序列不执行，若后续依赖循环内赋值的变量，会触发 `NameError`。

## 七、总结

- `while` 适合条件驱动、次数未知的循环；`for` 适合遍历有限可迭代对象。
- 写循环前先给出**终止性论证**与**循环不变量**，这是正确性的两个支点。
- `break` / `continue` / `else` 的语义要精确掌握：`else` 绑定“正常结束”，`break` 只跳一层。
- 遍历中不要修改被遍历容器；需要索引用 `enumerate`，需要并行用 `zip`。
- 嵌套循环注意复杂度和 `break` 的作用范围。
