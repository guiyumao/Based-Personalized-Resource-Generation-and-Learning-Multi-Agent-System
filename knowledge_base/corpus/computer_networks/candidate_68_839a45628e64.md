### 数据链路层：组帧、差错控制、可靠传输与介质访问控制

## 考纲定位

数据链路层是 408 选择题稳定产出区：功能、组帧、差错控制（检错纠错编码）、滑动窗口可靠传输（停等、GBN、SR）、介质访问控制（信道划分、随机访问 CSMA 系、轮询）、局域网（以太网 802.3、802.11、VLAN）、广域网 PPP、链路层设备（以太网交换机）。每年 2~3 道题。

## 功能与组帧

主要功能：封装成帧、透明传输、差错检测、流量控制。组帧方法：字符计数法、字节填充法（转义符）、比特填充法（HDLC，遇 5 个连续 1 插 0）、违规编码法。

## 差错控制

- 检错编码：奇偶校验（检奇数位错）、CRC 循环冗余校验（模 2 除法，收发双方约定生成多项式；CRC 只检错不纠错，由高层重传处理）。
- 纠错编码：海明码——r 个校验位可纠 1 位错满足 2^r ≥ k + r + 1；海明距 d 检错位数 d-1、纠错位数 ⌊(d-1)/2⌋。

## 流量控制与可靠传输

- 停止-等待协议：发一帧等一个确认，信道利用率 U = T_D / (T_D + RTT + T_A)；出错重传由超时计时器触发。
- 后退 N 帧 GBN：发送窗口 W ≤ 2^n - 1（n 位序号），累积确认，出错处之后全部重传；接收窗口 = 1。
- 选择重传 SR：发送窗口与接收窗口均 ≤ 2^(n-1)，逐帧确认逐帧重传。
- 窗口关系：停等 W=1 ≤ GBN ≤ SR；信道利用率 SR 最高。

## 介质访问控制

- 信道划分：FDM/TDM（及 STDM 统计时分）/WDM/CDM（码分多址，正交码片内积为 0，A 收 B：向量规格化内积判 0/1）。
- 随机访问：纯 ALOHA（想发就发，吞吐率 18.4%）、时隙 ALOHA（时间片对齐，36.8%）；CSMA（1-坚持、非坚持、p-坚持）；CSMA/CD（有线以太网）：先听后发、边听边发、冲突停发、随机重发（截断二进制指数退避），争用期 2τ，最小帧长 = 2τ × 数据率（10Mb/s 以太网 64B）；CSMA/CA（无线 802.11，用 ACK、IFS、退避与预约避免冲突，不能边听边发因无线自环检测不到冲突）。
- 轮询：令牌传递协议（令牌环），无冲突、负载重时效率高。

## 以太网与交换机

- 以太网（IEEE 802.3）：CSMA/CD + 曼彻斯特编码，帧格式 = 目的 MAC(6B) + 源 MAC(6B) + 类型(2B) + 数据(46~1500B) + FCS(4B)；MAC 地址 48 位，前 3 字节厂商标识 OUI，全 1 为广播地址；适配器（网卡）。
- 交换机：多端口网桥，自学习建立 MAC 地址表（源地址 → 入端口），按目的地址转发/过滤，全双工无冲突，每个端口一个冲突域；可同时多对端口并行转发。生成树协议 STP 防环路。
- VLAN：802.1Q 帧插入 4B 标签，隔离广播域，跨交换机 VLAN 通过 Trunk 传输。

## PPP 与广域网

PPP 面向字节：标志字段 0x7E 首尾定界、地址控制无意义、协议字段区分网络层、FCS；含 LCP（链路控制）与 NCP（网络控制，协商 IP）；字节填充实现透明传输；不需要流量控制与纠错（交给高层）。

## 高频考查方式与易错点

1. 最小帧长与最大传输距离换算：最小帧长 = 2 × 传播时延 × 速率。
2. GBN/SR 窗口上限与序号位数关系；给序号位数求最大窗口。
3. 交换机自学习与转发过程题：先查表，无表项则洪泛（除入端口）。
4. CRC 计算在收到的比特串后补 (生成多项式位数-1) 个 0 再做模 2 除。
