### 网络层：IPv4、子网划分、路由算法与路由协议

## 考纲定位

网络层是 408 计算题最密集章节：网络层功能与路由算法、IPv4 分组格式、IPv4 地址与 NAT、子网划分与 CIDR、ARP/DHCP/ICMP、IPv6、路由协议（RIP/OSPF/BGP）、IP 组播、移动 IP、网络层设备（路由器）。

## IPv4 分组

首部固定 20B：版本(4b)、首部长度(4b，单位 4B，最大 60B)、总长度(16b，单位 1B)、标识 + 标志(DF/MF) + 片偏移(单位 8B) 用于分片、TTL(每过一路由器减 1，为 0 丢弃)、协议字段(6=TCP, 17=UDP)、首部校验和（只查首部）。

- 分片计算：数据部分每片 ≤ (MTU - 首部) 且为 8 的倍数（最后一片除外）；片偏移 = 该片数据起点在原数据中的位置 / 8。同一数据报各片标识相同。

## IP 地址与子网划分（计算题核心）

- 分类地址：A 类 0 开头（1~126），B 类 10 开头（128~191），C 类 110 开头（192~223）；特殊地址：全 0（本机/默认路由）、全 1（受限广播 255.255.255.255）、主机号全 1（直接广播）、127 回环、169.254 链路本地。
- 子网划分：主机号借位做子网号；掩码 1 的位数为网络 + 子网位。可用子网数 = 2^借位数（或 2^借位数 - 2 按旧约定），每个子网可用主机数 = 2^主机位 - 2。
- CIDR 无分类编址：a.b.c.d/n，聚合构成超网；路由聚合取各网络地址公共前缀。给定地址块求可用地址数、判断某地址是否属于某块、最长前缀匹配选路，是每年必考技能。
- NAT：私网地址（10/8、172.16/12、192.168/16）通过路由器转换表（私有 IP:端口 ↔ 公网 IP:端口）访问外网，节约地址。

## ARP、DHCP、ICMP

- ARP：同一网段广播 ARP 请求（目的 MAC 全 F），目标主机单播应答映射 IP→MAC；跨网段则对默认网关 MAC 发请求。ARP 欺骗风险。
- DHCP：应用层协议，基于 UDP，客户端 68 / 服务器 67 端口；流程 Discover（广播）→ Offer → Request（广播）→ ACK；支持租用期与中继代理跨网段分配。
- ICMP：差错报告（终点不可达、源点抑制、超时 TTL=0、参数问题、改变路由）与询问（回送请求/应答 → ping；时间戳）。PING 与 Traceroute（利用 TTL 递增 + ICMP 超时/端口不可达）基于 ICMP；ICMP 封装在 IP 中但不属于传输层。

## 路由算法与协议

- 静态/动态路由；距离-向量算法（RIP，最多 15 跳、16 = 不可达，与相邻路由器周期交换整张路由表，存在"坏消息传得慢"/计数到无穷问题，用水平分割缓解）；链路状态算法（OSPF，洪泛链路状态通告 LSA，Dijkstra 计算最短路径树，触发式更新，区域划分减少开销，直接用 IP 封装协议号 89）；层次路由（自治系统 AS 内 IGP / 间 EGP）。
- BGP：AS 间路由，eBGP/iBGP，基于 TCP 179 端口，策略型路径向量协议。
- IPv6：128 位地址，冒号十六进制 + 零压缩；首部固定 40B、取消校验和与首部选项（扩展首部链式）、不允许分片（由源端处理）、只支持无连接；过渡技术：双协议栈、隧道。

## 路由器与组播、移动 IP

- 路由器任务：分组转发（查路由表，最长前缀匹配）与路由选择；隔离冲突域和广播域。路由表条目：目的网络 / 掩码 / 下一跳 / 接口；默认路由 0.0.0.0/0。
- IP 组播：D 类地址 224.0.0.0~239.255.255.255 标识组，硬件组播地址映射到 MAC 前 25 位；IGMP 管理组成员，组播路由协议（PIM 等）构建分发树。
- 移动 IP：永久地址（归属）+ 转交地址（外部代理），归属代理隧道封装转发。

## 高频考查方式与易错点

1. 子网划分/聚合/最长前缀匹配综合计算：先把地址展开成二进制再比较。
2. 分片计算中片偏移单位是 8B、总长度单位是 1B、首部长度单位是 4B。
3. RIP 与 OSPF 的对比（交换内容、算法、封装、规模）混淆。
4. ARP 属于网络层与链路层之间的协议（教材归网络层），DHCP 是应用层基于 UDP。
