# 计算机网络物理层

## 一、定义与适用条件

物理层是 OSI 参考模型的最底层，也是 TCP/IP 体系中网络接口层之下的功能划分。它负责在传输介质上透明地传输**比特流**，即把上层交来的数据帧转换为适合介质传输的信号，并在接收端把信号还原为比特流。

物理层关心的核心问题不是“帧里装了什么”，而是：

1. 用什么样的信号表示 0 和 1（编码与调制）；
2. 信号在介质上能传多快、多远（带宽、速率、衰减、失真）；
3. 收发双方如何同步（位同步、时钟恢复）；
4. 多个设备如何共享同一介质（复用与介质访问的物理基础）；
5. 接口的机械、电气、功能、规程特性（连接器形状、电平范围、引脚定义、时序）。

**适用条件**：讨论物理层时，默认上层（数据链路层）已经完成帧的封装与差错检测，物理层只保证“比特尽量正确、按序到达”的电气与信号层面问题。物理层本身不提供可靠传输、不提供寻址、不做流量控制。若问题涉及“帧丢失重传”“MAC 地址”“交换机转发”，则已超出物理层范围。

## 二、原理与推导

### 2.1 信号与信道的基本关系

物理层的性能由三个量刻画：**带宽**（介质能通过的频率范围，单位 Hz）、**信噪比**（信号功率与噪声功率之比，常以 dB 表示）、**传输速率**（bit/s）。

奈奎斯特准则给出理想无噪声低通信道的极限码元速率：

```
C = 2W · log2(V)   （bit/s）
```

其中 W 为带宽（Hz），V 为每个码元可取的离散电平数。它说明：带宽固定时，想提高速率只能增加电平数，但电平数增加会压缩判决裕量。

香农公式给出有噪声信道的极限信息速率：

```
C = W · log2(1 + S/N)   （bit/s）
```

其中 S/N 是线性信噪比。若给定信噪比以 dB 表示，先换算：`S/N = 10^(dB/10)`。香农给出的是理论上界，实际系统达不到；奈奎斯特给出的是理想条件下的码元速率上界。两者常被混用，需注意前提不同：前者针对无噪声、离散电平；后者针对有噪声、连续信道容量。

### 2.2 编码与调制

**编码**把比特映射为电平波形，常见有：

- 不归零（NRZ）：高电平表示 1、低电平表示 0，实现简单，但长串相同比特时无跳变，接收端难以提取时钟；
- 曼彻斯特编码：每个比特中间必有跳变，跳变兼作时钟，接收端易同步，但所需带宽约为 NRZ 的两倍；
- 差分曼彻斯特：以比特开始处有无跳变表示 0/1，抗极性反转能力更强。

**调制**把基带信号搬移到适合介质（如无线、光纤特定波长）的频带，常见有幅移键控 ASK、频移键控 FSK、相移键控 PSK，以及把幅度与相位联合使用的 QAM。QAM-16 每码元携带 4 bit，QAM-64 每码元携带 6 bit，这正是奈奎斯特公式中 log2(V) 的体现。

### 2.3 传输介质与复用

介质分导引型（双绞线、同轴电缆、光纤）与非导引型（无线电、微波、红外）。双绞线通过绞合抵消部分电磁干扰；光纤利用全反射约束光信号，衰减小、抗电磁干扰强。

复用让多路信号共享一条物理链路：

- 频分复用 FDM：不同信号占用不同频段，同时传输；
- 时分复用 TDM：不同信号轮流占用同一频段的不同时隙；
- 波分复用 WDM：光纤中不同波长并行传输，本质是光域的 FDM；
- 码分复用 CDM：各用户使用相互正交的码片序列，在同一频段同时发送。

### 2.4 物理层与上层的关系

物理层向数据链路层提供的是“比特管道”。数据链路层把帧交给物理层，物理层加上前导码（用于接收端位同步）后串行发送；接收端检测到前导码、恢复时钟、逐位采样，凑齐一帧后上交。物理层不识别帧边界之外的语义，也不做重传。

## 三、完整步骤：一次比特传输的物理层流程

以“主机 A 通过双绞线向主机 B 发送一帧”为例，物理层侧的处理可分解为：

| 步骤 | 操作 | 关键检查 |
|---|---|---|
| 1 | 数据链路层交付完整帧 | 帧已封装，长度在接口允许范围内 |
| 2 | 选择编码方式（如曼彻斯特） | 编码后带宽是否超出介质与收发器能力 |
| 3 | 添加前导码与帧起始定界符 | 前导码长度符合所用标准 |
| 4 | 串行化：并行字节转为比特流 | 比特顺序（先发低位还是高位）与标准一致 |
| 5 | 驱动发送器，按电气规范输出电平/光功率 | 电平在接收端可识别范围内，不超驱动上限 |
| 6 | 信号经介质传播，经历衰减与失真 | 链路长度、接头数量在预算内 |
| 7 | 接收端检测信号、恢复时钟、逐位采样 | 采样点位于码元中心附近 |
| 8 | 去掉前导码，把比特流交回数据链路层 | 比特数与帧长一致，无插入/丢失 |

**状态表**（接收端同步过程）：

| 状态 | 输入条件 | 动作 | 下一状态 |
|---|---|---|---|
| 空闲 | 无有效信号 | 等待 | 空闲 |
| 检测到前导码 | 电平跳变符合前导码模式 | 启动时钟恢复 | 同步中 |
| 同步中 | 连续跳变稳定 | 锁定位边界 | 已同步 |
| 已同步 | 收到帧起始定界符 | 开始按帧长采样 | 接收中 |
| 接收中 | 采样计数达到帧长 | 上交比特流 | 空闲 |

## 四、可验算案例

**案例（奈奎斯特准则）**：某理想无噪声低通信道带宽 W = 3 kHz，采用 4 电平编码，求极限码元速率与数据速率。

- 码元速率 = 2W = 6000 Baud；
- 每码元比特数 = log2(4) = 2 bit；
- 数据速率 = 6000 × 2 = 12000 bit/s = 12 kbit/s。

**代回验算**：12 kbit/s ÷ 2 bit/Baud = 6000 Baud，恰为 2W，符合准则；若把电平数改为 8，则速率变为 6000 × 3 = 18 kbit/s，说明电平数增加确实提高速率，但判决裕量下降，实际系统需留余量。

**案例（香农公式）**：信道带宽 W = 3 kHz，信噪比 30 dB，求容量。

- 30 dB 对应 S/N = 10^(30/10) = 1000；
- C = 3000 × log2(1001) ≈ 3000 × 9.97 ≈ 29.9 kbit/s。

**代回验算**：若把结果代回，2^(C/W) = 2^9.97 ≈ 1001，减 1 得 1000，与给定信噪比一致，说明换算无误。注意此例中香农容量（约 29.9 kbit/s）高于上例奈奎斯特结果（12 kbit/s），二者前提不同，不能直接比较优劣。

## 五、边界与反例

1. **物理层不保证可靠**：比特在介质上可能因噪声翻转，物理层不做检错重传；检错由数据链路层的帧校验完成。反例：认为“物理层传输出错会自动重发”是错误认识。
2. **带宽不等于速率**：带宽是频率范围（Hz），速率是比特率（bit/s）。反例：把“100 MHz 带宽”直接说成“100 Mbit/s”混淆了量纲。
3. **曼彻斯特编码带宽代价**：它用两次电平跳变表示一个比特，所需带宽约为 NRZ 的两倍，不能既要求强同步又要求与 NRZ 同带宽。
4. **香农公式不是实现指标**：它给出上界，实际调制解调器受实现复杂度、编码、协议开销限制，达不到该值。
5. **复用不增加总容量**：FDM/TDM 是把一条链路的能力分给多路，总速率受介质与收发器限制，不是“每路都独享全带宽”。
6. **介质长度受预算约束**：双绞线超长会导致衰减与串扰超限，不能仅靠提高发送功率无限延长，因为功率过大会加剧串扰并违反电气规范。

## 六、常见错误

- 把物理层与数据链路层的职责混淆，例如认为物理层负责 MAC 寻址或帧校验；
- 计算奈奎斯特速率时忘记乘 2W 中的 2，或把 log2(V) 误写成 V；
- 信噪比 dB 与线性值换算错误，例如把 30 dB 当作 30 倍；
- 认为“数字信号传输不需要考虑带宽”，忽略编码后信号占用的频带；
- 把“码元速率（Baud）”与“比特率（bit/s）”等同，忽略每码元可携带多比特；
- 认为光纤完全不受物理损伤影响，忽略弯曲损耗与连接器污染；
- 在讨论复用方式时把 CDM 与 TDM 混为一谈，前者靠正交码区分，后者靠时隙区分。

## 七、总结

物理层解决“比特如何变成信号、信号如何经介质到达对端并被正确采样”的问题。它的核心量是带宽、信噪比与速率，核心工具是编码、调制、复用与介质规范。奈奎斯特准则刻画理想无噪声信道的码元速率上界，香农公式刻画有噪声信道的容量上界，二者前提不同、不可混用。物理层只提供比特管道，不提供可靠传输与寻址；其性能受介质长度、接头、电气规范约束。掌握物理层，应能区分“信号层面”与“帧层面”的职责边界，能对给定带宽、电平数或信噪比做小规模定量估算并代回验算，能识别带宽与速率、Baud 与 bit/s、dB 与线性值等常见混淆。
