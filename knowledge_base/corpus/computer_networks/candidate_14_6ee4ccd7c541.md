## 考纲定位

考纲物理层：信道/信号/码元/波特/速率等概念、奈奎斯特定理与香农定理、编码与调制、电路/报文/分组交换、数据报与虚电路、传输介质、物理层设备。每年 1~2 道计算或概念选择题。

## 基础概念

- 码元：固定时长的信号波形，代表 k 进制的一位；码元速率（波特率）B 与信息速率（比特率）关系：R = B × log2(N)（N 为码元离散状态数）。
- 信源、信宿、信道；模拟信号与数字信号；基带信号与宽带（通带）传输。

## 两大定理（计算必考）

- 奈奎斯特（无噪声、理想信道）：极限波特率 B = 2W（W 为信道带宽 Hz）；数据率 R = 2W log2 N b/s。限制的是码元速率，与编码状态数无关上限。
- 香农（有噪声）：极限数据率 C = W log2(1 + S/N) b/s，信噪比 dB = 10 log10(S/N)。dB 与倍数换算：3dB=2倍，10dB=10倍，20dB=100倍，30dB=1000倍。
- 两定理同时适用时取较小者；提高带宽或信噪比或编码状态数可提升速率，但码元速率受奈氏限制。

## 编码与调制

- 数字数据编码：归零制 RZ、不归零制 NRZ、反向不归零 NRZI、曼彻斯特编码（每个码元中间跳变，兼作时钟与数据，以太网使用，波特率是比特率 2 倍）、差分曼彻斯特（码元开始处有无跳变定 0/1）、4B/5B 编码。
- 调制：ASK、FSK、PSK、QAM（幅相联合，状态数 = 幅度数 × 相位数）。

## 交换技术

- 电路交换：建立连接 → 通话 → 释放，通信期间独占资源，时延小、无冲突，适合实时大流量；线路利用率低。
- 报文交换：存储转发整个报文，无长度限制，时延大。
- 分组交换：报文分组存储转发，时延较小、灵活、利用率高；开销有分组头和排队时延。数据报方式（无连接，各分组独立选路可能失序）与虚电路方式（逻辑连接，按序到达，分组只需带虚电路号）。
- 计算题：比较三种交换传送 x bit 报文的总时延——电路交换 = 连接建立时间 + 发送时延 + 传播时延；分组交换 = (分组数 × 单组发送时延) + (跳数-1)×单组发送时延 + 传播时延，注意流水线重叠。

## 传输介质与设备

- 导向介质：双绞线（UTP/STP）、同轴电缆、光纤（单模远距离激光、多模近距离发光二极管）；非导向：无线电波、微波、红外。
- 物理层接口四特性：机械、电气、功能、规程（过程）。
- 设备：中继器（再生信号，两端同一网段，5-4-3 规则）、集线器 Hub（多端口中继器，一个冲突域，半双工，逻辑总线）。

## 高频考查方式与易错点

1. 奈氏与香农同时给条件时选较小值；波特率与比特率混算。
2. dB 换算错误：信噪比给 dB 要先换算成倍数再代入香农公式。
3. 曼彻斯特编码速率折半（10Mb/s 以太网需 20Mbaud）。
4. 数据报与虚电路的连接性、分组头、按序到达等特征对比表记忆。
