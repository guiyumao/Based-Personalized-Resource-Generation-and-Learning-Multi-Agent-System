### 计算机网络体系结构与参考模型

## 考纲定位

考纲第一章：计算机网络的概念、组成与功能、分类、性能指标；分层结构、协议/接口/服务概念；OSI 参考模型与 TCP/IP 参考模型。每年 1~2 道选择题，是后续所有章节的框架。

## 基本概念

- 计算机网络 = 结点 + 链路的互连集合，功能包括数据通信（连通性）与资源共享，另分布处理、可靠性、负载均衡。
- 组成：硬件（主机、路由器、交换机等）、软件、协议（三要素：语法、语义、同步/时序）。
- 按分布范围分 WAN/MAN/LAN/PAN；按拓扑分总线、星型、环型、网状；按交换技术分电路交换、报文交换、分组交换。

## 性能指标（计算题高频）

- 带宽：最高数据率 b/s。时延 = 发送（传输）时延 + 传播时延 + 处理时延 + 排队时延；发送时延 = 分组长度 / 带宽，传播时延 = 信道长度 / 传播速率（铜线/光纤约 2×10^8 m/s，常取 2×10^8 或 3×10^8）。
- 时延带宽积 = 传播时延 × 带宽（"以比特为单位的链路长度"）；往返时延 RTT。
- 速率单位换算：k=10^3（速率），存储 K=2^10。信道利用率 = 有数据通过时间 / 总时间。

## 分层与服务

- 分层原则：每层相对独立、功能等价、下层为上层提供服务、层间通过接口交互。
- 协议是水平的（对等实体间规则），服务是垂直的（下层向上层提供）。服务原语：请求、指示、响应、证实；面向连接服务与无连接服务的区别。
- SDN 数据平面与控制平面分离的基本概念、拥塞控制基本概念在近年考纲中列入本章了解即可。

## OSI 七层 vs TCP/IP 四层

OSI（物、数、网、传、会、表、应）理论完整；TCP/IP（网络接口层、网际层、传输层、应用层）实践主流。常考各层功能与设备对应：

- 物理层：比特传输，中继器、集线器。
- 数据链路层：成帧、差错控制、流量控制，网桥、交换机（二层）。
- 网络层：路由选择、拥塞控制、网际互连，路由器（三层）；OSI 网络层提供无连接 + 面向连接，TCP/IP 网际层仅无连接（IP）。
- 传输层：端到端可靠/不可靠传输（TCP/UDP），端口寻址。
- 会话层（建立管理会话、同步）、表示层（编码转换、加密压缩）仅 OSI 有；TCP/IP 把它们并入应用层。
- 应用层：为用户应用提供服务（HTTP、DNS、FTP 等）。

## 封装与解封装

发送方自上而下逐层加头部：应用报文 → TCP 段（加 TCP 头）→ IP 数据报（加 IP 头）→ 帧（加帧头帧尾）→ 比特流；接收方自下而上解封装剥去各层头部。数据在各层的称谓：应用层报文、传输层段（TCP segment / UDP 数据报）、网络层分组/数据报、链路层帧。

## 高频考查方式与易错点

1. 各层设备归属：交换机二层、路由器三层、集线器一层（冲突域 vs 广播域：交换机隔离冲突域不隔离广播域，路由器都隔离）。
2. 发送时延与传播时延的计算与主导因素（带宽影响前者，距离影响后者）。
3. 协议三要素对应错题干描述。
4. 会话层/表示层功能张冠李戴。
