## 考纲定位

408 考纲第一部分为数据结构基本概念与算法分析：数据、数据元素、数据对象、数据结构及其逻辑结构与存储结构的关系；算法的定义与特性（有穷性、确定性、可行性、输入、输出）；算法时间复杂度与空间复杂度的分析。历年稳定出 1~2 道选择题（约 2~4 分）。

## 逻辑结构与存储结构

- 逻辑结构四类：集合、线性结构、树形结构、图形结构（网状结构）。
- 存储结构（物理结构）四类：顺序存储、链式存储、索引存储、散列存储。
- 逻辑结构独立于计算机，存储结构依赖于计算机；同一逻辑结构可以有多种存储实现，运算的定义针对逻辑结构，运算的实现针对存储结构。

## 时间复杂度

时间复杂度度量的是基本操作的执行次数 T(n) 的数量级，记 O(f(n))，取最高阶项并忽略系数。

常见量级从小到大：O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)。

典型结论：
- 单层循环 n 次 → O(n)；双重嵌套循环 → 常见 O(n^2)。
- 循环变量每次乘 2 或除 2（i = i * 2）→ O(log n)。
- 折半查找 O(log n)，快排平均 O(n log n) 最坏 O(n^2)，堆排序与归并排序稳定 O(n log n)。
- 递归算法的时间复杂度 = 递归调用次数 × 每次递归中的基本操作代价；分析时可借助递推式（主定理）。

最好、最坏与平均时间复杂度：例如顺序查找最好 O(1)、最坏 O(n)、平均 O(n)（成功查找平均比较 (n+1)/2 次）。408 题目常给一段代码求数量级，重点是找出与规模 n 相关的最深层基本语句并统计次数。

## 空间复杂度

空间复杂度度量算法运行中辅助空间（额外空间）关于 n 的数量级，不计输入数据本身占用的空间。

- 原地（in-place）算法：辅助空间 O(1)，如冒泡排序、插入排序、堆排序。
- 递归算法要计入递归工作栈：快排平均 O(log n)、最坏 O(n)；归并排序需 O(n) 辅助数组。

## 高频考查方式与易错点

1. 给代码段求 T(n) 的数量级——先找最内层语句，再按循环变量增长方式（线性/倍增/嵌套）求和。
2. 混淆"时间复杂度"与"实际执行时间"：复杂度只刻画增长趋势。
3. 忽略递归栈的空间开销，误判递归算法空间复杂度为 O(1)。
4. 认为存储结构决定逻辑结构（因果关系颠倒）。
