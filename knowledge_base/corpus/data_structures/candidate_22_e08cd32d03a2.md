## 考纲定位

树与二叉树是 408 分值最重的章节之一：树的性质、二叉树定义与特性、存储结构、四种遍历、线索二叉树、树/森林与二叉树转换、哈夫曼树与并查集。每年 3~5 道选择，综合题常考遍历相关算法设计。

## 树的基本性质

- 结点数 = 分支数 + 1；度为 m 的树第 i 层至多 m^(i-1) 个结点；高度为 h 的 m 叉树至多 (m^h - 1)/(m-1) 个结点。
- 度为 m、结点数为 n 的树中，叶结点数 n0 = n - (分支结点总数)；对任意树有 n0 = 1 + n2 + 2n3 + ... + (m-1)nm（度按结点计）。

## 二叉树的重要性质

- 第 i 层至多 2^(i-1) 个结点；高度 h 的二叉树至多 2^h - 1 个结点。
- 叶结点 n0 与度为 2 的结点数 n2 满足 n0 = n2 + 1。
- 完全二叉树：n 个结点高度 ⌈log2(n+1)⌉ 或 ⌊log2 n⌋ + 1；按层编号 i，则 ⌊i/2⌋ 是双亲，2i、2i+1 是左右孩子（存在时）。
- n 个结点的二叉树形态数为卡特兰数；n 个结点、有 m 个叶结点的二叉树对应 m 个空链域（n+1 个空指针）。

## 遍历

先序（根左右）、中序（左根右）、后序（左右根）递归与非递归实现都要会；层序用队列。

核心结论（选择题高频）：
- 中序 + 先序 / 中序 + 后序 / 中序 + 层序，任两组（必须含中序）可唯一确定二叉树；先序 + 后序不能唯一确定。
- 先序序列中，某结点的所有后代都出现在其后；后序相反。
- 由先序 + 中序（或后序 + 中序）可唯一重建二叉树，重建后再推后序/先序或画树是常考操作。
- 后继线索遍历：在中序线索树中找指定结点中序后继 O(1)，先序后继/后序前驱也可能 O(1)，但先序前驱、后序后继通常需双亲信息。

非递归遍历要点：中序——沿左子树入栈直到 NULL，弹栈访问后转右子树；后序需标志位或双栈。

## 线索二叉树

利用 n+1 个空指针存放前驱/后继线索，需增设 ltag/rtag 标志（0 表示孩子，1 表示线索）。中序线索树中，结点的后继 = 右标志为 1 时右线索所指，否则右子树最左下结点。

## 树、森林与二叉树的转换

- 树转二叉树：左孩子右兄弟表示法；树转的二叉树根无右子树。森林转二叉树：各棵树转换后依次连接到前一棵树根的右链上。
- 树的先根遍历 = 对应二叉树的先序遍历；树的后根遍历 = 对应二叉树的中序遍历。森林的先序和中序遍历与对应二叉树一致。

## 哈夫曼树与并查集

- 哈夫曼树：带权路径长度 WPL = Σ wi × li 最小的二叉树。构造：每次取两棵最小权树合并。n 个叶结点的哈夫曼树共 2n-1 个结点，无度为 1 的结点。哈夫曼编码：左 0 右 1，前缀码，总长最短；n 个叶结点编码平均长度 = WPL / Σwi。
- 并查集：双亲表示法存储，Find 与 Union；按秩合并 + 路径压缩后单次操作近似 O(α(n))，常用于判断连通性、Kruskal 造最小生成树。

## 高频考查方式与易错点

1. 由两种遍历序列画树或反推第三种序列——必须含中序。
2. 完全二叉树编号性质与结点计算。
3. 混淆树的先根/后根与二叉树先序/后序的对应（是先序/中序）。
4. 线索二叉树中判断某指针指向：先分清 ltag/rtag 含义再推理。
