## 本知识点要点（考研向）

### 排序：内部排序算法对比与外部排序

## 考纲定位

排序是 408 高频章节：插入（直接/折半/希尔）、冒泡、快排、简单选择、堆排、归并、基数排序的原理、一趟结果、比较次数、稳定性与复杂度，以及外部排序（败者树、置换选择、最佳归并树）。每年 2~4 道选择，易出"给序列问第 k 趟结果"。

## 各排序要点

- 直接插入：逐个把元素插入有序前缀；基本有序或 n 小时效率高；最好 O(n)（已有序），平均/最坏 O(n^2)；稳定；折半插入比较次数降为 O(n log n) 但移动次数不变，仍 O(n^2)，稳定。
- 希尔排序：按增量分组做插入排序，增量逐轮缩小到 1；复杂度约 O(n^1.3)，依赖增量序列；不稳定；仅适用于顺序存储。
- 冒泡排序：相邻逆序交换，每趟把当前最大（或最小）冒到端部；某趟无交换可提前结束（已有序时最好 O(n)）；最坏/平均 O(n^2)；稳定。
- 快速排序：取枢轴划分（常取首元素，双指针交替移动），枢轴每趟落定最终位置；平均 O(n log n)（比较次数约 n log2 n 量级），最坏 O(n^2)（基本有序时取首元素为枢轴最糟，改用随机/三者取中规避）；空间为递归栈，平均 O(log n) 最坏 O(n)；不稳定；n 大时平均性能最好。每趟至少一个元素（枢轴）就位。
- 简单选择排序：每趟选最值与前端交换，比较次数固定 n(n-1)/2 与初始序列无关；移动 ≤ 3(n-1)；不稳定。
- 堆排序：建堆 O(n) + n-1 次 O(log n) 调整，整体 O(n log n) 且最坏也 O(n log n)；空间 O(1)；不稳定；适合大规模与 Top-K。
- 归并排序：2 路归并需 O(n) 辅助数组；任何情况 O(n log n)；稳定；n 大且要求稳定或链表排序时优先。
- 基数排序：按最低位优先多趟分配收集，d 趟（d 为位数），每趟 O(n + r)（r 为基数）；总 O(d(n+r))；空间 O(r)；稳定；适用于位数少、n 很大的整数或定长字符串。

## 对比速记

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
|---|---|---|---|---|
| 直接/折半插入 | O(n^2) | O(n^2) | O(1) | 是 |
| 冒泡 | O(n^2) | O(n^2) | O(1) | 是 |
| 快排 | O(nlogn) | O(n^2) | O(logn) | 否 |
| 简单选择 | O(n^2) | O(n^2) | O(1) | 否 |
| 堆排 | O(nlogn) | O(nlogn) | O(1) | 否 |
| 归并 | O(nlogn) | O(nlogn) | O(n) | 是 |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(r) | 是 |

稳定的排序：插入、冒泡、归并、基数（口诀"插冒归基稳"）。

## 外部排序

多路归并减少 I/O：k 路归并 r 个初始归并段需 ⌈log_k r⌉ 趟。败者树使 k 路选最小只需 O(log k) 比较；置换选择排序生成平均长度 2×内存容量的初始段；最佳归并树（哈夫曼思想）安排归并顺序使 I/O 最少，段数不足补虚段（长度 0），需满足 (r-1) % (k-1) == 0。

## 高频考查方式与易错点

1. "第 1/2 趟后的结果"：快排一趟定一个枢轴；冒泡一趟冒一个最值；简单选择一趟选一个最值；堆排一趟后堆顶元素到末尾。逐趟模拟别跳步。
2. 稳定性判断与"任何情况复杂度都 O(n log n)"（归并、堆排）这类绝对化结论。
3. 快排递归深度与栈空间的关系。
4. 基数排序趟数由最大位数决定，与 n 无关。
