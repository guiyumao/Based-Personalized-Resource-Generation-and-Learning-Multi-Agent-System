### 栈与队列：定义、存储与应用

## 考纲定位

考纲要求：栈和队列的基本概念、顺序与链式存储结构、多维数组存储与特殊矩阵压缩存储、栈队列数组的应用（表达式求值、递归、缓冲区、迷宫等）。每年稳定 2~3 道选择题。

## 栈

后进先出（LIFO），只能在栈顶插入（push）与删除（pop）。

- 顺序栈：top 指向栈顶元素时，入栈先 S.data[++S.top]=x，出栈 x=S.data[S.top--]；栈满条件 top == MaxSize-1，栈空 top == -1（注意教材约定差异，看清题目给的 top 含义）。
- 共享栈：两栈顶相向，top1 = -1、top2 = MaxSize 时分别为空，top1 + 1 == top2 时栈满，充分利用空间。
- 链栈：用单链表实现，头插头删，栈顶在表头，不存在栈满；通常不设头结点。
- n 个不同元素进栈，出栈序列数目为卡特兰数 C(2n,n)/(n+1)，如 n=3 时 5 种。判断合法出栈序列：任何时刻已出元素之外，栈中元素从栈底到栈顶递减；典型非法序列如 3-1-2 型。

栈的应用：函数递归调用（系统栈保存活动记录）、表达式求值（中缀转后缀、后缀求值用栈暂存操作数）、括号匹配、深度优先搜索、进制转换。

## 队列

先进先出（FIFO），队尾插入、队头删除。

- 循环队列（顺序存储的标配）：牺牲一个单元区分空满时——队空 front == rear；队满 (rear+1) % MaxSize == front；元素个数 = (rear - front + MaxSize) % MaxSize。若增设 size 或 tag 变量，则可用满全部 MaxSize 个单元。
- 链式队列：带头结点单链表，front 指头结点、rear 指尾结点；队空 front == rear（都指头结点）。
- 双端队列：两端都可插入删除；输出受限/输入受限双端队列的可行的输出序列判断是常考题。

队列的应用：广度优先搜索、操作系统就绪队列与缓冲区、页面置换 FIFO。

## 数组与特殊矩阵压缩存储

- 一维数组 a[0..n-1] 地址 = 首地址 + i×元素大小；多维数组按行优先/列优先计算元素地址（必考计算题）。
- 对称矩阵压缩（行优先存入一维数组 B）：aij（i≥j，下三角）存于 B[i(i-1)/2 + j - 1]（1 起始下标时），共 n(n+1)/2 个元素。
- 三对角矩阵存 3n-2 个元素；稀疏矩阵用三元组 (行, 列, 值) 或十字链表存储，压缩后失去随机存取特性。

## 高频考查方式与易错点

1. 循环队列判满判空条件与元素个数计算——务必先确认"牺牲单元"还是"带 size/tag"。
2. 出栈序列合法性判断：先验序列法或模拟法都要熟练。
3. 矩阵压缩地址计算：确认下标从 0 还是 1 开始、行优先还是列优先。
4. 中缀转后缀、后缀求值步骤题：操作数直接输出，运算符按优先级进出栈。
