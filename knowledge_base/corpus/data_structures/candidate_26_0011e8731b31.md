## 考纲定位

## 基本概念与 ASL

平均查找长度 ASL = Σ pi × ci（pi 查找概率，ci 比较次数）。查找成功与查找失败要分别计算——408 计算题最常见的失分点是漏算"查找失败"的 ASL（失败位置数 = 判定树外部结点数 = n+1）。

## 顺序查找

对无序/有序表都适用，ASL(成功) = (n+1)/2；哨兵方式减少一次边界判断。有序表顺序查找失败时可以提前终止。

## 折半查找

仅适用于有序顺序表（链表不可）。mid = ⌊(low+high)/2⌋（或向上取整，按题目约定，判定树形态不同）。

- 判定树是平衡二叉树形态：n 个元素判定树高度 h = ⌈log2(n+1)⌉；查找成功最多比较 h 次，失败最多 h 或 h-1 次（取决于构造）。
- ASL(成功) ≈ log2(n+1) - 1（等概率）。例：n=15 时判定树为满树，成功 ASL = (1×1+2×2+3×4+4×8)/15 = 3.27。
- 折半查找与二叉搜索树的关系：折半查找过程即在一棵由有序表构造的判定树上走根到叶的路径。

## 分块查找

块间有序、块内无序：先折半（或顺序）查块，再块内顺序查。设 n 元素分 b 块每块 s 个：顺序查块 ASL = (b+1)/2 + (s+1)/2，最优 s = √n。

## 散列表

- 构造方法：除留余数法 H(key) = key % p（p 取不超过表长的最大素数最常用）、直接定址、平方取中、折叠法。
- 冲突处理：
  - 开放定址线性探测：冲突则 (H+i) % m 逐个后移。缺点：堆积（聚集）现象使非同义词争夺同一探测序列。删除只能做标记，不能物理删除。
  - 平方探测：(H ± i^2) % m，m 必须为 4k+3 型素数才能探测到全部槽位，缓解堆积。
  - 再散列、伪随机探测。
  - 链地址法：同义词链表，适合频繁删除；装填因子可 >1。
- 装填因子 α = 表中元素数 / 表长；ASL 与 α 直接相关而与表长无关。散列查找成功的 ASL 按每个元素的实际探测次数求平均，失败的 ASL 按 H(key) 的每个可能取值（p 个散列地址）从初始位置走到第一个空位的探测次数求平均。
- 计算题标准流程：按插入顺序逐个放元素（画出最终表）→ 统计每个元素比较次数得成功 ASL → 对每个初始散列地址数到第一个空槽得失败 ASL。

## 树型查找补充

BST、AVL 详见树章；红黑树结论：插入至多 2 次旋转、删除至多 3 次旋转；n 结点高度 ≤ 2log2(n+1)。

## 高频考查方式与易错点

1. 散列表 ASL 双指标计算：失败 ASL 的分母是散列函数值域个数 p，不是表长 m。
2. 线性探测删除元素后查找路径断裂问题（需懒惰删除）。
3. 折半查找判定树画法：mid 向下取整时左子树结点数 ≥ 右子树（多 0 或 1 个）。
4. 分块查找块内无序、块间有序这一前提别记反。
