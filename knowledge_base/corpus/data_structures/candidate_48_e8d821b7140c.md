### 二叉搜索树、平衡二叉树与 B 树

## 考纲定位

考纲"树型查找"与"B 树"部分：二叉搜索树（BST）、平衡二叉树（AVL）、红黑树、B 树与 B+ 树。BST/AVL 是选择题高频考点，B 树考插入删除后的结构，红黑树考性质与旋转次数结论。

## 二叉搜索树 BST

性质：左子树所有结点 < 根 < 右子树所有结点（无重复值时），中序遍历得递增有序序列。

- 查找：从根比较，相等成功，小于走左大于走右；查找长度不超过树高。查找成功的平均查找长度 ASL = Σ(每层结点数 × 层号)/n。
- 插入：查找失败位置处挂新结点，新结点必为叶。
- 删除：叶直接删；只有一棵子树则以子树顶替；有两个孩子时用中序前驱（左子树最右）或中序后继（右子树最左）替代后再删该替代结点。
- 相同关键字序列按不同插入顺序得到不同形态；n 个关键字可构造出不同的 BST。含 n 个结点的 BST 查找最坏 O(n)（单支树），最好 O(log n)（平衡时）。

## 平衡二叉树 AVL

任意结点左右子树高度差（平衡因子）的绝对值 ≤ 1。

- n 层 AVL 最少结点数递推：N(h) = N(h-1) + N(h-2) + 1，N(0)=0, N(1)=1, N(2)=2……由此得高度 h 的 AVL 至少含 N(h) 个结点，反推 h 与 n 的关系：h < 1.44 log2(n+2)。含 12 个结点的 AVL 最大高度为 4（常考）。
- 插入后失衡找最小失衡子树，分四类旋转：LL 型右单旋、RR 型左单旋、LR 型先左后右双旋、RL 型先右后左双旋。旋转后子树高度恢复为插入前高度，因此不必向上继续调整。
- 删除 AVL 结点可能引发多次旋转（旋转可向上传播）。
- AVL 查找时间 O(log n)。

## B 树与 B+ 树

- m 阶 B 树：根至少 2 棵子树 1 个关键字；非根非叶至少 ⌈m/2⌉ 棵子树（⌈m/2⌉-1 个关键字）；所有叶结点（失败结点）同一层；关键字有序，查找需在结点内顺序（或折半）+ 沿树下降。
- 插入：插入后关键字数超上限（m-1）则从中间关键字分裂为两半，中间关键字上移并入父结点，可能连锁分裂直至分裂根使树高 +1。删除：关键字不足下限（⌈m/2⌉-2 即低于 ⌈m/2⌉-1）时先借（兄弟够借则旋转借关键字），否则与兄弟合并，可能向上传播。
- B+ 树：n 棵子树的结点含 n 个关键字；叶结点包含全部关键字并链成有序链表，支持顺序查找与范围查询；非叶结点仅作索引。B+ 树中查找不成功最终必落到叶结点。区别于 B 树：B 树关键字只出现一次，查找可在中途命中。

## 红黑树（了解级结论）

- 五条性质：结点红或黑；根黑；叶（NIL）黑；红结点的孩子必黑（无连续红）；任一结点到其每个叶的路径含相同数目的黑结点（黑高相同）。
- 结论：n 个内部结点的红黑树高度 ≤ 2log2(n+1)；最长路径 ≤ 2×最短路径；插入至多旋转 2 次，删除至多旋转 3 次。

## 高频考查方式与易错点

1. 给序列逐个插入建 BST/AVL，问最终形态或某结点位置——一步一步画图，不要跳步。
2. AVL 旋转类型判断：找插入路径上离根最近的失衡结点，看其与孩子的两次走向命名（如 L 再 R 即 LR）。
3. B 树结点关键字数上下限记忆：非根非叶 ⌈m/2⌉ ≤ 子树数 ≤ m。
4. 混淆 BST 删除时"用前驱/后继替代"的操作对象。
